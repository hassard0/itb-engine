# legacy/

Standalone report-generator scripts from the early ITB program (v1.0–v1.19,
2026-05). They produced the first-generation `docs/results/2026-05-08-*` notes
(baseline battery, intersection search, Bayesian genealogy, robustness maps, etc.).

They are kept for provenance but are **not** part of the current engine — the live
research lives in `experiments/` (cycle scripts) and `src/itb/` (the library). These
import `itb` and can still be run, but the modern equivalent of "run a study" is a
script under `experiments/`.

See [`../docs/results/INDEX.md`](../docs/results/INDEX.md) for the full chronology.
