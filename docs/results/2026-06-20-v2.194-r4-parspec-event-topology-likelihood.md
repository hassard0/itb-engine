## What Ran

The artifact keeps the v2.193 source-event rerun, but replaces the fixed H1/L1
topology with the event-specific detector topology declared by the public GWOSC
manifest:

```text

  H1 = H-H1_GWOSC_4KHZ_R1-1126259447-32.hdf5
  L1 = L-L1_GWOSC_4KHZ_R1-1126259447-32.hdf5

GW200129_065458-v1:
  H1 = H-H1_GWOSC_4KHZ_R1-1264316101-32.hdf5
  L1 = L-L1_GWOSC_4KHZ_R1-1264316101-32.hdf5
  V1 = V-V1_GWOSC_4KHZ_R1-1264316101-32.hdf5
```

For every event/detector pair, Vulcan computed event-time LALSuite antenna
moments using the same grid convention as v2.183:

```text
ra_count = 8
dec_count = 7
psi_count = 6
sample_count = 336
weighting = cos(dec)
```

Those event-time channel responses are then passed into the coarse v2.187 R4
likelihood path as explicit detector-channel response overrides.
