# v1.71 — The basis extension that makes RG-monotonicity load-bearing: the a/c conformal-collider wedge

**Date:** 2026-06-08
**Compute:** Vulcan (16-core); central-charge numbers settled against the standard free-field table (Dr. M. consult tangled the arithmetic; corrected here).

---

## The setup — finishing v1.70

v1.70 ended with a precise diagnosis: the a-theorem (and every other anomaly /
RG-monotonicity bound) was **dormant** because the toy basis used a single
curvature-squared coupling g_R2 to stand in for **both** 4d Weyl-anomaly central
charges,

        <T^mu_mu> = c·Weyl² − a·Euler ,

so a and c were degenerate and there was no direction for a ratio bound to
constrain. v1.71 does the one thing that diagnosis called for: **resolve the
basis.** We add a second curvature-squared coupling **g_C** (the Weyl²
coefficient) so the engine can separate

        g_R2  ↔  a  (Euler / Gauss-Bonnet)        g_C  ↔  c  (Weyl²).

## The new constraint — Hofman–Maldacena wedge

Hofman–Maldacena (2008) energy-flux positivity at a conformal collider bounds the
ratio of central charges for any unitary 4d CFT with a stress tensor:

        1/3  ≤  a/c  ≤  31/18  ≈  1.722 .

**Settling the numbers** (the standard free-field table, `⟨T⟩ = c·W² − a·E`,
`a = (n_s + 11n_f + 62n_v)/360`, `c = (n_s + 6n_f + 12n_v)/120`):

| free field | a | c | a/c |
|---|---|---|---|
| real scalar | 1/360 | 1/120 | **1/3** (floor) |
| Weyl fermion | 11/360 | 6/120 | 11/18 ≈ 0.61 (interior) |
| Maxwell vector | 62/360 | 12/120 | **31/18** (ceiling) |

scalar saturates the floor, Maxwell the ceiling — exactly the wedge endpoints.
(Dr. M.'s draft mis-set the fermion's c = 1/120 instead of 6/120 and chased a
phantom inconsistency; the corrected table above closes it.)

With a ∝ g_R2 and c ∝ g_C (same constant, so a/c = g_R2/g_C, c = g_C > 0):

        3·g_R2 − g_C       ≥ 0      (a/c ≥ 1/3)
        31·g_C − 18·g_R2   ≥ 0      (a/c ≤ 31/18)

i.e. **(18/31)·g_R2 ≤ g_C ≤ 3·g_R2**. Implemented as `HofmanMaldacenaWedge`
(`src/itb/constraints/hofman_maldacena.py`), wired into the canonical
`build_stack` (now 36 constraints). Pure two-derivative GR (g_R2 = g_C = 0) has no
curvature-squared sector and is **not** a CFT with higher-curvature anomalies, so
the bound is treated as *inapplicable* (vacuously satisfied) there — not violated.

## It bites — and the wedge is the sole excluder

The decisive test (`experiments/ac_wedge.py`): a string-like survivor point
(g_4=0.5, g_6=0.4, g_8=0.4, g_R2=0.2, g_R3=0.15) with **g_C = 0.05**, so
a/c = 0.2/0.05 = **4.0**, above the 31/18 ceiling.

| | old stack (no wedge) | new stack (+wedge) |
|---|---|---|
| witness (a/c = 4) | **feasible** | **excluded** |
| sole failing constraint | — | `hofman_maldacena_wedge` |

Because g_C enters **only** the wedge, the rest of the stack is unchanged, so the
wedge is provably the *only* thing excluding the witness. Contrast v1.70, where
the a-theorem flipped **nothing**. The basis extension turned a dormant principle
into a load-bearing one.

Across the (g_R2, g_C) plane (121×121, [0,0.7]²), the wedge is the **dominant**
binding constraint — **5276 cells**, more than RFC (2705), forward positivity
(1497), or the CFT bound (829). The feasible region (11%) is the green band
**between the two wedge rays**; see `ac_wedge.png`.

## Where the frameworks sit — the honest part

With the default g_C = g_R2 (a/c = 1) every framework sits on the **a/c = 1
holographic diagonal**, dead-center in the wedge:

| framework | a/c (default) | wedge |
|---|---|---|
| pure GR | — (inapplicable) | ✓ vacuous |
| string-EFT, asymptotic-safety, LQG, CDT | 1.0 | ✓ pass |

This is **not** a weakness, it is the physics: a/c = 1 is the generic holographic
expectation — two-derivative Einstein duals force a = c, and only higher-derivative
bulk corrections (a Gauss-Bonnet term) shift c − a. So the wedge does **not** bite
the default framework points; it bites theory-space points whose a/c strays from
1 (toward a free-scalar-like c-rich corner, or a vector-like a-rich corner). The
engine now has a genuine handle on the **c − a** direction it was previously blind
to, and the moment a framework is given a non-trivial Weyl² coefficient (a/c ≠ 1),
the wedge will test it.
