# v2.455 - the candidate's cosmic birefringence is isotropic: the anisotropy probes f_a (a Planckian-axion discriminator)

Complementing v2.451 (the isotropic angle β ~ α_EM). The same axion θ that gives the isotropic birefringence also
acquires quantum fluctuations during inflation, δθ ~ H_inf/(2π f_a), imprinting an **anisotropic** birefringence
field:

```text
  delta_beta / beta  ~  delta_theta / Delta_theta  ~  H_inf / (2pi f_a Delta_theta)
```

Unlike the isotropic angle, this ratio depends on H_inf/f_a — so **the anisotropy probes the axion decay constant
f_a directly**. For the candidate's heterotic model-independent axion (f_a ~ M_Pl, H_inf ~ 6×10⁻⁶ M_Pl, Δθ ~ O(1)):

```text
  delta_beta/beta ~ 1e-6   =>   delta_beta ~ 3e-7 deg   (current bound ~0.1 deg)  =>  NEGLIGIBLE anisotropy
```

So the candidate predicts a birefringence **isotropic to ~10⁻⁶** — essentially no anisotropy. 5/5 checks pass.

## The discriminator

To make the anisotropy **observable** (δβ ~ 0.01–0.1°, i.e. δβ/β ~ 0.03–0.3) would require **f_a ~ 10¹³–10¹⁴ GeV
(sub-Planckian)** — *not* the model-independent axion. So:

- **A detection of anisotropic cosmic birefringence** at any observable level would **disfavor** the candidate's
  Planckian-f_a heterotic-axion identification (v2.434).
- **A continued null** is exactly what the candidate predicts.

The anisotropy amplitude is a clean, model-independent-axion-vs-lower-scale-axion **discriminator on f_a**. This
adds a fourth entry to the scale-clean birefringence story — the isotropic size (~α_EM), the handedness (>0), the
primordial-tensor chirality (suppressed, v2.444), and now the anisotropy (suppressed, an f_a probe) — all pointing
to a Planckian-decay-constant axion, each falsifiable in a specific direction.

## Honest scope

An **order-of-magnitude** estimate. δβ/β ~ H_inf/(2π f_a Δθ) is the standard axion-fluctuation result
(Caldwell–Gluscevic–Kamionkowski 2011); H_inf ~ 6×10⁻⁶ M_Pl is the real Starobinsky value (from A_s), f_a ~ M_Pl is
the standard model-independent-axion scale (but the exact value is compactification-dependent — precisely what the
anisotropy probes), and Δθ ~ O(1) is a plausibility input. The robust content is the **parametric** statement:
δβ/β ~ H_inf/(2π f_a), ~10⁻⁶ for a Planckian f_a and observable only for a sub-Planckian f_a — a monotonic probe of
f_a. The specific 3×10⁻⁷° is illustrative; the current ~0.1° bound is a rough figure. A consistency/discriminator
statement, not a detection forecast.
