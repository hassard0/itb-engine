## Question

v2.12 identified a stale topology path: `experiments/phases.py` still used a
7-coefficient basis and omitted the Weyl-squared coordinate `g_C`. This cycle asks:

1. Can the phase-connectivity experiment run in the current 8D basis?
2. Does adding `g_C` change the qualitative topology picture?
3. What is the honest interpretation of straight-line components?

## Method

The experiment now uses:

```python
["g_4", "g_6", "g_8", "g_R2", "g_R3", "g_C", "g_R2_parity", "g_R3_parity"]
```

It finds diverse feasible seeds by multistart optimization, deduplicates near-identical
seeds, and connects two seeds only when the straight segment between them is feasible.

Important caveat: a straight edge proves two seeds are connected, but absence of a straight
edge does not prove disconnection. A curved feasible path can still merge components.

## Interpretation

This upgrades v1.28-style phase mapping to the current 8D basis. The result is not a proof
of four disconnected UV phases. The honest statement is narrower:

> In the 8D corrected-stack seed graph, feasible samples cluster into four straight-line
> lobes near the data-driven branch, corresponding to the four parity-sign quadrants.

That is still useful. It says the topology-sensitive part of the current island is not the
old 7D matter/graviton slice; it is the parity sector wrapped around a live `g_C` axis.

## Next loop

The missing test is curved-path connectivity. The next cycle should replace or augment

## Bottom line

The topology test no longer omits `g_C`. At 600 and 1200 seeds it consistently finds four

defensible discriminator, but still not a solution to quantum gravity.
