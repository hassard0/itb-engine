# v2.464 - a scale-clean UV-embedding test: the curvature double-ratio D = (g_R2·g_R4)/g_R3² evades the string-scale wall

The heterotic UV embedding (v2.434) was "blocked on the string scale." In an α′ expansion the dimensionless
curvature couplings scale as

```text
  g_R2 ~ x c_2 ,  g_R3 ~ x^2 c_3 ,  g_R4 ~ x^3 c_4 ,   x = alpha' M_Pl^2 = (M_Pl/M_string)^2
```

(c_n the O(1) α′-coefficients; each R^n enters at order α′^{n−1}). The **individual** ratios are scale-dependent —
g_R3/g_R2 ~ x·c_3/c_2 needs the unknown x — which is exactly why comparing the candidate to a string prediction was
blocked.

But the **double-ratio**

```text
  D = (g_R2 g_R4)/g_R3^2 = (x^1 · x^3)/(x^2)^2 · (c_2 c_4/c_3^2) = c_2 c_4/c_3^2    (net x-power 4 - 4 = 0)
```

has x **cancel** — D is a pure number fixed by the heterotic α′-coefficients. This extends v2.451's insight
(scale-independent quantities evade the string-scale wall) from *observables* to the *UV embedding* itself. 5/5
checks pass.

## The candidate value and the test

With g_R2 = 0.193, g_R3 = 0.09 and g_R4 at the curvature moment-tower floor (g_R4 ≥ g_R3²/g_R2 = 0.042):

```text
  g_R4 = 0.042 -> D = 1.00   (moment-tower floor)
  g_R4 = 0.050 -> D = 1.19
  g_R4 = 0.080 -> D = 1.91
```

So the candidate predicts **D ≥ 1** (the rigorous moment-tower inequality g_R3² ≤ g_R2·g_R4, v2.375), with the
constructed point at the floor (D ~ 1). A heterotic computation of **D_string = c_2 c_4/c_3²** (from the tree-level
R²:R³:R⁴ coefficients, *no string scale needed*) would confirm or refute the embedding scale-cleanly: D_string ≥ 1
is required for moment-tower consistency, and D_string ~ D_candidate would support the heterotic identification.
**For the first time the heterotic-embedding question has a concrete, scale-independent target number** — the wall
that stopped v2.434 is gone for this observable.

## Honest scope

The scale-independence of D is a **robust, exact** consequence of the standard α′ power-counting — the x-powers
cancel identically (4−4=0), the genuine new content. But this cycle does **not** compute D_string: the heterotic
α′-coefficients c_2, c_3, c_4 are a string-theory input I don't derive, and the higher-curvature action beyond R²
Gauss-Bonnet is **scheme/field-redefinition-dependent** (R³, R⁴ coefficients are basis-dependent — a real
subtlety), so the test is *opened, not executed*. The candidate's D = 1 is at the moment-tower **floor** because
the Chebyshev-center point saturates the tower — so "D ~ 1" is a constructed-point feature; the robust candidate
statement is only D ≥ 1. This is a **method** result: it identifies a scale-clean UV-embedding observable and gives
its candidate value, not a completed embedding test.
