## Method

The harness loads the v2.122 detector alpha/nuisance likelihood cube and uses
the identical H1/L1 nuisance grids as one shared event nuisance index:

```text
joint log L(alpha, nuisance) = log L_H1(alpha, nuisance) + log L_L1(alpha, nuisance)
joint log L_marginal(alpha) = logmeanexp_nuisance(joint log L)
```

It also checks the null likelihood scale at alpha zero. Because each detector
uses normalized whitened data, the alpha-zero residual likelihood is:

```text
expected per detector = -0.5
expected H1+L1 network = -1.0
```

The adapter gate was hardened so `claim_ready` is false whenever any
`claim_blocker` remains, including `g8_joint_component_missing`.

## Interpretation

The alpha side is now internally consistent for this route: component
systematics are bounded, the likelihood is joint over the shared nuisance grid,
