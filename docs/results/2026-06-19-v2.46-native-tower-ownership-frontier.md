## Pass Condition

A future row moves the frontier only if it clears all of:

- reference-feasible and in engine scope
- native `TowerEvidence` present
- truthy framework-owned endpoint metadata
- truthy framework-owned displacement metadata
- generic claim guard ready
- `phi_tower_mean - 2 * phi_tower_sigma > critical_phi_tower`

At the current threshold, that means the two-sigma lower tower coordinate must
exceed `0.7433019116911739`.
