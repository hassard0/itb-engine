# v2.236 - How a deformation lifts the GR-zero tidal Love number: the new-physics signal

## Question

v2.235 verified the GR black-hole tidal Love number is exactly zero. This cycle computes the
SIGNAL: how a non-Kerr / higher-curvature / exotic-compact-object deformation induces a NONZERO Love
number -- the tidal-sector analog of the v2.231 photon-sphere-deviation null test.

## Method

A naive outward integration of the deformed static equation is ill-conditioned (the tiny induced
`x^{-l-1}` response tail is swamped by the `x^l` growing tidal field). The stable, correct route is
FIRST-ORDER perturbation theory on the self-adjoint static operator
`[(1-x^2) y']' + [l(l+1) - 4/(1-x^2)] y = 0`. Deforming the potential by `eps * V(x)`, the
horizon-regular solution's induced decaying-tail coefficient is

```text
(B/A) = -(eps / W0) * INTEGRAL_1^inf  V(x) * P_l^2(x)^2  dx        (k_l proportional to B/A)
```

a convergent overlap integral of known functions -- no unstable integration.

## Result

For `l=2` and `V = 1/x^n` (a near-horizon deformation), the response overlap integral, verified
against its closed form:

```text
  n     overlap I = int P_2^2(x)^2 / x^n dx     closed form     match
  6        4.80000                               4.80000         yes
  8        0.68571                               0.68571         yes
 10        0.22857                               0.22857         yes

 GR baseline (eps = 0): response = 0          linear in eps: yes (x2 -> x2, x4 -> x4)
```

**Any localized deformation lifts the GR-zero Love number, linearly in the deformation strength.**
The induced response is exactly zero with no deformation (the v2.235 GR baseline) and scales as
`eps`. The sensitivity DECREASES with deformation localization (larger `n` -> smaller overlap with
the `x^l` tidal field). So a measured nonzero tidal Love number is the new-physics signal, and this
overlap integral is the transfer function mapping a near-horizon deformation to the observable -- the
tidal-sector counterpart of the v2.231 photon-sphere-deviation null test.

localized deformation lifts it linearly with a computable transfer function (the `P_l^2`-overlap

(tidal) -- each with its GR null and its deformation sensitivity.

reported quantity is the response OVERLAP INTEGRAL (and a proxy `B/A` with a representative Wronskian
`W0 = 24`); the absolute Love-number value folds in the convention normalization (the `M^{2l+1}`
