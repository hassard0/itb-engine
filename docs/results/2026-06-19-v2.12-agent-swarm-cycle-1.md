## Result 1 - the island exists, but the number depends on the sampling box

The parity-even island census found **1,786 survivors / 300,000 samples**:

- volume fraction: **0.00595 +/- 0.00014** in the stated parity-even comparable-magnitude box.
- PCA participation ratio: **3.448**.
- 90% variance requires **5** principal components; effective dimension is about **3.4**.
- nearest survivor walls: `generalized_anomaly_inflow` dominates the boundary, followed by `bekenstein_tight`, `dispersion_tower_g6_squared_bound`, `scalar_convexity_g6_vs_g4`, and `cross_sector_efthedron`.

This supports the robust qualitative claim from v2.07/v2.10: the allowed region is non-empty and low-dimensional. It does **not** make the exact volume a physical number. The Jenga/adversarial runs use a different full 8D box and get **77 / 300,000** theoretical survivors, so the fair claim is structural, not numerical.

## Result 3 - the parity/data-driven branch is conditional on birefringence

The alternative-birefringence run makes the central contingency explicit:

- canonical beta = 0.34, sigma = 0.09: `discovered_data_driven` posterior **0.9992** against the parity-even survivor.
- null beta = 0: parity-even `string_tree_eft` wins by parsimony; data-driven posterior is **0.5** because the extra parity coupling is unnecessary.
- decisive pivot at current hint precision: beta about **0.193**.
- decisive pivot at LiteBIRD-like sigma = 0.03: beta about **0.065**.

So the strongest fair claim is: if the cosmic-birefringence hint is real, the engine favors a screened-scalaron, positive-parity data-driven EFT. If the hint is null, that branch collapses to a parity-even survivor. This is a clean discriminator, not a solved theory.

## Adversarial review

The team rejected any "solved quantum gravity" wording.

Current fair headline:

> ITB is a disciplined toy EFT discriminator with useful self-audits. It has not solved quantum gravity.

Reasons:

- The top gatekeeper, `swampland_distance_conjecture`, is encoded as a static coefficient hierarchy prior, not a derivation of the Distance Conjecture in a dynamical moduli space.
- Toy prefactor robustness does not cover functional-form risk. RFC and BNOSSW already showed that the wrong functional form can create false exclusions.
- Framework verdicts are verdicts on coefficient encoders, not on full UV theories.
- Data constraints must be labeled as current data, hint, forecast, or scenario assumption.
- The data-driven EFT was constructed to track beta, so its Bayesian win measures contingency on the birefringence hint, not independent confirmation.
