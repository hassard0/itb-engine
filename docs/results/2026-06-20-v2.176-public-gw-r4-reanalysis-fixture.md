## Source Inputs

The fixture uses the GWOSC GW170608 v3 event record and H1/L1 strain-file
contracts as public inputs, with the v2.175 Bresciani axis dictionary as the R4
axis contract. The current GWOSC catalog page reports that GWTC is a cumulative
catalog and, as of this run, lists 391 events including newer GWTC-5.0 entries.
The fixture deliberately keeps GW170608 because the repo already has a
reproducible public-strain connector and alpha-likelihood lineage for that
event.

## Fixture Boundary

The emitted packet is manifest-complete and adapter-ingestible, but its R4
waveform response and covariance are deterministic synthetic controls. It proves
that the software path is now connected:

```text
GWOSC public input declaration
  -> linearized R4 waveform fixture
  -> Bresciani axis sidecar
  -> v2.160 packet
  -> v2.162 shape score
```

It does not prove an R4 constraint from public GW data.

## Claim Boundary

The remaining real-reanalysis blockers are:

```text
r4_waveform_response_model_is_fixture
public_r4_reanalysis_samples_missing
waveform_systematics_not_closed_for_r4
external_adversarial_review_missing
```

The correct next artifact is a real LALSuite-compatible R4 waveform response
that reuses this packet export path but replaces the synthetic covariance with
public GW170608 posterior samples or a reproducible likelihood grid.
