# v2.14 - Parity bridge diagnostic: the four lobes are a distance-prior artifact

**Date:** 2026-06-19
**Compute:** local diagnostic plus Vulcan re-run against the v2.13 1200-seed artifact
**Stack:** `build_stack(bnossw_mean="geometric", rfc_form="convex_hull")`

## Question

v2.13 found four straight-line components in the full 8D phase graph. The open question was
whether those components are real disconnected phases or an artifact of straight-line
connectivity. This cycle tests the obvious curved bridge: detour through the parity-zero
plane.

## Method

Input: `experiments/results/v2.13/phases_8d_1200.json`.

For each of the four v2.13 component centroids:

1. Set `g_R2_parity = g_R3_parity = 0` while holding all other coefficients fixed.
2. Check whether that parity-zero projection is feasible.
3. Check whether all parity-zero projections are mutually connected by straight segments.
4. Scan the straight descent from the original centroid to its parity-zero projection and
   record the first failing constraint.

Command:

```bash
python experiments/phase_bridges.py \
  --input experiments/results/v2.13/phases_8d_1200.json \
  --out experiments/results/v2.14/phase_bridges_1200.json \
  --samples 101
```

## Result

Every parity-zero projection is feasible. The parity-zero projections are mutually
connected. But every continuous straight descent into that parity-zero plane fails first
on the same constraint:

```json
{"swampland_distance_conjecture": 4}
```

The first failure occurs before the parity coefficients reach zero:

| component | first failing t | blocker | margin |
|---:|---:|---|---:|
| 0 | 0.16 | `swampland_distance_conjecture` | -0.154 |
| 1 | 0.17 | `swampland_distance_conjecture` | -0.209 |
| 2 | 0.16 | `swampland_distance_conjecture` | -0.028 |
| 3 | 0.21 | `swampland_distance_conjecture` | -0.076 |

The worst margins become enormous near parity zero because the current distance-prior
encoding computes:

```text
max(abs(g_*)) / min(abs(g_*), nonzero) <= 20
```

with `min_threshold = 1e-6`. A coefficient exactly equal to zero is ignored, but a tiny
nonzero coefficient becomes the denominator. Therefore the feasible set has a discontinuous
punctured gap around the parity-zero plane: exactly zero parity is allowed, moderately
nonzero parity can be allowed, but arbitrarily small nonzero parity is excluded.

## Interpretation

The v2.13 four-component result should **not** be interpreted as four physical quantum
gravity phases. The more accurate statement is:

> The four straight-line parity lobes are caused by the hard nonzero-threshold aspect-ratio
> encoding of the swampland distance prior.

This is a useful negative result. It identifies the exact reason straight-line topology
over-splits the island: the current Distance Conjecture proxy is discontinuous at zero
coefficients. That discontinuity dominates the topology question.

## What this corrects

v2.13 was careful not to claim a topology theorem, but it still left open whether the four
lobes might be meaningful parity-sign phases. v2.14 closes that interpretation under the
current encoding: the lobe split is an artifact unless the distance prior is replaced by a
continuous functional form and the split survives.

1. island census,

The curved-bridge diagnostic downgrades the four v2.13 parity lobes from candidate physical
phases to an encoding artifact of the hard Distance Conjecture proxy. This is progress: the
engine found and documented a failure mode in one of its most load-bearing constraints.
