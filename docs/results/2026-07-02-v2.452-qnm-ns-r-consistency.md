# v2.452 - the inflation consistency relation r = 3(1−n_s)²: a scale-independent, parameter-free prediction pinning r ≈ 0.0037

Staying in the dimensionless vein v2.451 opened. The candidate's R² (Starobinsky) inflation gives, to leading
order in the e-fold number N:

```text
  n_s = 1 - 2/N ,   r = 12/N^2   =>   eliminate N   =>   r = 3 (1 - n_s)^2
```

N drops out; no scale enters. This is a **parameter-free relation between two observables** — scale-independent,
exactly the spirit of the α_EM birefringence (v2.451). It converts the standalone "r ~ 0.004" into a **sharp joint
prediction**:

```text
  Planck n_s = 0.9649 +/- 0.0042   =>   r = 3(1-n_s)^2 = 0.0037 (+0.0009 / -0.0008)   [N ~ 57]
```

**LiteBIRD** (σ(r) ~ 0.001) can test the relation directly: r ≈ 0.0037 confirms the R² plateau; an r far off the
line r = 3(1−n_s)² (r > 0.01, or r ≪ 0.002 at this n_s) falsifies it. 5/5 checks pass.

## Why this matters

The candidate now carries **two scale-independent predictions touching data** — **β ~ α_EM** (birefringence size,
v2.451) and **r = 3(1−n_s)²** (the inflation consistency line) — neither needing the string scale or any O(1)-toy
magnitude. Both are pure dimensionless statements the near-term experiments test. This sharpens the inflation front
from a single number to a **falsifiable relation**, and it composes with the g_R2 over-determination (v2.442): the
same scalaron must give r *on the consistency line* **and** w > −1 in the dark energy, so a joint (n_s, r, w)
measurement over-tests the single-scalaron picture on a scale-independent footing.

## Honest scope

r = 3(1−n_s)² is the standard R²/Starobinsky consistency relation to leading order in 1/N, and it is
**plateau-class** — shared by any plateau/R²-like model (Higgs inflation, α-attractors at large N approach the same
line), so a confirmation validates the plateau *class*, not uniquely *this* candidate (same status as v2.442's n_s,
r). It's genuinely scale-independent and parameter-free — the point — but not candidate-unique. There are finite-N
and reheating corrections to the leading n_s, r (a few % in n_s, order-1 relative in r), so r = 0.0037 is a
leading-order value with ~10–20% theory uncertainty atop the n_s-propagated band; the *relation* is robust to
leading order. Planck's n_s is real data; LiteBIRD's σ(r) ~ 0.001 is the design target.
