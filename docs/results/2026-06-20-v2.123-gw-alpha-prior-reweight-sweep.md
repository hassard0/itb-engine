## Method

The harness loads the v2.122 detector-by-detector likelihood cube and reweights
the nuisance axis directly, without rerunning LALSuite. The declared prior
catalog contains 13 factorized priors:

```text
uniform grid control
broad event-centered prior
tight event-centered prior
low/high total-mass sidebands
low/high eta sidebands
early/late coalescence-time sidebands
negative/positive phase sidebands
lower/upper combined boundary stresses
```

For each prior, the harness computes:

```text
log L_prior(alpha) = sum_detector logsumexp_nuisance(log L_detector(alpha, nuisance) + log w_prior(nuisance))
```

The stability rule is intentionally conservative for this coarse alpha grid:

```text
max best-cell movement <= one alpha-grid cell per axis
best-vs-GR log-likelihood gain <= 0.01
```

## Interpretation

The v2.121 prior blocker is now converted into bounded evidence for the declared
catalog. The actual cube reweighting does not create a meaningful non-GR alpha
preference: the biggest shift is one coarse grid cell per axis and the largest
best-vs-GR log-likelihood gain is far below the configured tolerance.

This is not a final discriminator. The result still uses the detector-separable
cube semantics inherited from v2.115, not a full joint-event posterior, and it
does not close waveform, EFT truncation, likelihood-scale, or G8 systematics.
