## Source Algorithm

Ng's `src/scripts/kappa_constraint_restricted.py` builds one Gaussian KDE per
event-level `kappa` posterior, evaluates each KDE on a uniform grid from
`-0.1` to `0.1`, sums the log densities, normalizes the product by trapezoidal
integration, and interpolates the source-style CDF at 5, 50, and 95 percent.

The reproduced run uses:

| item | value |
|---|---:|
| samples | `710000` |
| events | `71` |
| samples per event | `10000` |
| grid | `[-0.1, 0.1]` with `1000` points |
| density norm | `1.0` |
