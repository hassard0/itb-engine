## What Ran

The artifact reuses the v2.187 coarse R4 waveform-likelihood machinery and runs
it on the H1/L1 32-second public GWOSC strain records for:

```text
GW150914-v3:
  H1 = H-H1_GWOSC_4KHZ_R1-1126259447-32.hdf5
  L1 = L-L1_GWOSC_4KHZ_R1-1126259447-32.hdf5

GW200129_065458-v1:
  H1 = H-H1_GWOSC_4KHZ_R1-1264316101-32.hdf5
  L1 = L-L1_GWOSC_4KHZ_R1-1264316101-32.hdf5
```

The shared strain-conditioning path was made event-GPS-aware so source-event
strains are not sliced around the old GW170608 GPS. The default remains
backward-compatible for existing GW170608 runs.


The main technical caveat is intentional: GW200129_065458-v1 has public V1
strain, but the engine's calibrated R4 detector-channel response is still H1/L1
only. This artifact therefore proves an H1/L1 same-event rerun, not a
claim-grade replication of the full ParSpec source-event detector topology.

## Claim Boundary

The correct claim is:

```text
The engine has rerun its coarse R4 H1/L1 likelihood path on the two ParSpec
source events using public GWOSC strain and LALSuite on Vulcan.
```

The incorrect claim would be:

```text
The engine has produced a claim-grade ParSpec/qEFT R4 posterior or framework
exclusion.
```

No framework exclusions are claimable from this artifact.
