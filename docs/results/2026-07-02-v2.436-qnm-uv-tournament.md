## What this establishes

**The candidate is not string-unique.** Four paradigms sit in the rigorous cage and are parity-deformation
reachable; only LQG is rigorously excluded. Among the R²-bearing UV completions the candidate *requires* (v2.434),
string is closest and best-motivated (its model-independent axion gives the cleanest parity story), but **CDT is a
near-tie (0.085) and asymptotic safety is genuinely competitive (0.196)** — and the low-energy EFT the engine
carves **cannot rule them out.** The candidate is a **convergence point of multiple UV completions**, and
discriminating string vs CDT vs asymptotic safety needs genuinely UV / quantum-gravity data — the actual UV
behaviour (a string tower, a discrete-spacetime continuum limit, or a UV fixed point) — which amplitude-carving of
a low-energy EFT does not access.

This is the honest broadening asked for: **there are other viable solve-paths (CDT and asymptotic safety, not only
string).** And it **tempers v2.434**: the bold "it *is* heterotic" must read "**heterotic/string is the *leading*
candidate UV completion among several the low-energy data cannot yet separate.**" It also sharpens what a genuine
QG-*solving* measurement must do: not just confirm the candidate (the correlated 2030 signature, v2.430) but
**reach the UV to discriminate the completions** — a distinct, harder observational target than the low-energy
fronts.

## Honest scope

The frameworks are the engine's schematic O(1) *encoders* of each paradigm's low-energy dim-8 coefficients, not
computed spectra — so "CDT reaches the candidate" is a structural statement about the encoders, not a proof a real
CDT continuum limit yields the candidate (same caveat as the string identification). Distances use dimensionless
O(1) couplings (toy). The string–CDT gap (0.067 vs 0.085) is small and *within* the O(1) encoder uncertainty —
which is exactly why "not string-unique" is the honest reading. This **tempers but does not overturn** v2.434:
heterotic remains best-motivated (the axion), and "not type II" stands (pure-GR's no-R² point is far).
