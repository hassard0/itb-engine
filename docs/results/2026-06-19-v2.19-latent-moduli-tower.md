## Question

v2.18 closed the simple tower-norm loop: continuous species/tower priors are better
diagnostics than the hard max/min distance prior, but at `N_max=3.0` they are redundant
with existing aggregate curvature constraints.

v2.19 asks whether making the missing chain explicit changes anything:

```text
Wilson coefficients -> latent modulus distance -> tower mass -> species cutoff
```

This is still not a physical Swampland Distance Conjecture implementation. The latent
coordinate is inferred from the same Wilson-coefficient basis, not from a derived
moduli-space metric. The species cutoff is `1/sqrt(N_tower)`, not a self-consistent
solution of a full `N(Lambda, d)` equation. The value is diagnostic: it makes the
assumptions inspectable.

## Diagnostic Form

Each candidate chooses a curvature-sector reference direction and computes:

```text
radial_coordinate = projection of (g_R2, g_C, g_R3) onto reference direction
latent_distance   = log(1 + kappa * radial_coordinate)
tower_mass        = exp(-lambda_tower * latent_distance)
N_tower           = radial_species + transverse_mismatch + parity_mismatch
species_cutoff    = 1 / sqrt(N_tower)
```

Four reference/mismatch variants were tested:

- `centroid_radial`
- `centroid_transverse`
- `data_driven_transverse`
- `string_transverse`

The output also records parameter sensitivity over `lambda_tower`, `kappa`, and
transverse weight, plus an `N_max` acceptance sweep.

## Interpretation

This is another negative independence result, but a useful one.

v2.19 improves the audit surface: the artifact now exposes a latent distance, tower mass,
species count, species cutoff, monotonicity checks, parameter sensitivity, topology
checks, framework verdicts, and overlap counts. That is a stronger diagnostic object than
the hard max/min prior or the v2.17 aggregate norms.

It still does not buy independent discrimination in this basis. At `N_max=3.0`, all four
latent variants are permissive on the v2.13 lobe/bridge region. When transverse variants
fail broad stress points, the failures continue to overlap `species_scale_bound` and
`complexity_cutoff`.

The next serious move is not another latent scalar coordinate over the same coefficients.
It is a new basis element: an explicit tower spectrum or moduli coordinate that can vary
independently of the curvature-load sector.
