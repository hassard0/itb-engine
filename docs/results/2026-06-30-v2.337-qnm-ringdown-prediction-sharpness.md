# v2.337 - The ringdown prediction is a firm floor but a loose magnitude (vs the sharp parity prediction)

## Question

v2.336 gave the moment-tower FLOOR on the constructed theory's ringdown-active quartic curvature `g_R4`.
What is the full feasible RANGE -- is the ringdown prediction sharp, or only floored? And how does it
compare to the sharp, data-pinned parity prediction?

## Result (an honest asymmetry: floor firm, magnitude loose)

```text
  moment-tower floor:      g_R4 >= 0.042
  feasible range:          g_R4 in [0.05, 0.60]   (width 0.55, ~169% relative spread, a ~10x window)
  ceiling set by:          complexity_cutoff (a THEORY constraint, not data)

  parity prediction:       ~15% spread (data-pinned, sharp -- v2.334)
```

The constructed theory's `g_R4` spans a WIDE range. The floor is firm (the moment-tower mandate
`g_R4 >= g_R3^2/g_R2 = 0.042`, v2.336), so a nonzero minimum ringdown deviation is guaranteed; but the
ceiling (0.60) is the complexity cutoff, and nothing in between pins `g_R4` -- because NO data constraint
reads it (`g_R4` is the opt-in curvature-tower coupling, observationally unconstrained, only theory-bounded).
By contrast the parity coupling is pinned by the cosmic-birefringence data to ~15%. All 5/5 checks pass.

## What this establishes

The honest shape of the constructed theory's testability is asymmetric: a SHARP parity prediction
(data-pinned, the headline) and a FLOORED-BUT-LOOSE ringdown prediction (theory-bounded). The ringdown
channel can CONFIRM a minimum quartic-curvature deviation -- and a ringdown consistent with pure GR below
the floor would REFUTE the theory -- but it does not sharply predict the deviation's size. The reason is
clean: the cosmic-birefringence data pins the parity coupling, but no current measurement touches `g_R4`, so
a future curvature-sector measurement sensitive to `g_R4` would be needed to sharpen the ringdown the way
birefringence sharpened the parity. The v2.336 ringdown discriminator (ordering candidates by their floor)
stands; this cycle adds that the floor, not the magnitude, is the firm part.

## Honest scope

The `g_R4` range and the ceiling constraint are the engine's literal feasibility verdict with the curvature
tower on; the floor (`g_R3^2/g_R2`) is exact. The exact range [0.05, 0.60] depends on the complexity-cutoff
prefactor (c_max and the `g_R4` weight as a dimension-8 operator), so the WIDTH is convention-dependent --
the robust content is the CONTRAST: the ringdown (`g_R4`) is only theory-bounded (floor firm, magnitude
loose) because no data constraint reads it, while the parity is data-pinned (sharp). The ~15% parity spread
is the v2.334 value (itself contingent on the birefringence data, v2.329). The `g_R4 ->` ringdown-shift size
remains schematic (rank-1 qNM->R^4, v2.336), so "a minimum ringdown deviation" refers to the `g_R4` floor,
not a sourced frequency shift. This is a curvature-sector (CP-even) characterization, independent of the
cosmic-birefringence data. Toy basis, O(1) prefactors.
