## The Wald-positivity constraint — a consistent restatement, not a new wall

`WaldEntropyPositivity` (ΔS_ext ≥ 0) is wired into `build_stack` as a theoretical
axiom. It **newly excludes no survivor**: g_C ≥ 0 (c-anomaly unitarity / the HM
wedge) and g_4 ≥ 0 (forward positivity) already guarantee ΔS ≥ 0. So — like the
a-theorem (v1.70) — it is an *implied* condition in the current basis, retained as
an explicit, separately-citable consistency statement that would only bite in an
enlarged basis where g_C or g_4 could go negative. Its value is conceptual: it shows
the engine's amplitude/holographic positivity and black-hole thermodynamics are the
*same* statement, seen from two sides.

The ΔS–WGC magnitude correlation across frameworks is weak (~0.21): the CLR
equivalence is about the **sign** (both positive for all consistent theories), not
the precise magnitude ordering, which tracks different coefficient combinations.
That is the honest, correct reading.
