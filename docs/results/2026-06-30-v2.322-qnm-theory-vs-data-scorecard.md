# v2.322 - Theory vs data: no named framework satisfies both, but a constructed one does

## Question

The capstone question of the program: scored on BOTH theoretical consistency and current observational
data, which candidate higher-derivative gravity survives?

## Result (a sharp dichotomy; only a constructed framework satisfies both)

Separating the engine's constraints into THEORETICAL consistency (convex_hull) and the four INGESTED-DATA
constraints (GW170817 speed, GW dispersion, cosmic birefringence, sub-mm gravity):

```text
  candidate            theory_ok   data_ok   satisfies both
  pure_gr               yes         NO        no   (data-excluded: cosmic birefringence)
  string_tree_eft       yes         NO        no
  asymptotic_safety     yes         NO        no
  cdt                   yes         NO        no
  lqg_induced           NO          yes       no   (theory-excluded: outlier g_R3)
  engine_constructed    yes         yes       YES
```

NO named framework satisfies both. The four parity-EVEN frameworks are theoretically feasible but
DATA-EXCLUDED -- they predict zero cosmic birefringence, which the measured `beta = 0.34 +/- 0.09 deg`
(~3.6 sigma) rules out; parity-evenness FORCES `beta = 0`, so this exclusion is a symmetry statement,
robust to the prefactors. lqg is the mirror image: DATA-FAVORED (parity-violating, so it matches `beta`)
but THEORY-INFEASIBLE (its outlier cubic curvature `g_R3`, v2.311). Each named framework fails exactly one
axis.

A CONSTRUCTED framework -- string-like matter (`g_4, g_6, g_8 ~ 0.5/0.4/0.4`), trimmed curvature
(`g_R2 ~ 0.19, g_R3 ~ 0.09`), and a parity coupling `g_R2_parity = 0.06` in the v2.321 joint window
[0.048, 0.078] -- satisfies BOTH the full consistency stack AND all four data constraints. All 4/4 checks
pass.

## What this establishes (the program's headline)

The engine constructs the unique candidate consistent with current theory and current data, where every
community proposal is excluded on one side. Assembled from the corrected, audited pieces, that candidate is
a higher-derivative gravity that is string-like in its matter sector, has its curvature couplings trimmed
into the consistent interior, and carries the mild right-handed parity violation that anomaly matching
prefers (v2.318), the cosmic birefringence data requires (v2.321), and a future chiral-GW measurement would
test (v2.319). It is a theory the engine builds precisely because none of the named ones can be both
consistent and observed.

## Honest scope

All values are the engine's literal `check()` output under convex_hull with all four data constraints
enabled. The robust, prefactor-independent content is the DICHOTOMY: parity-even frameworks predict
`beta = 0` and are excluded by the nonzero cosmic-birefringence measurement (a symmetry statement), while
lqg is the named framework that fails theory. The named frameworks' THEORY-feasibility is
canonical-prefactor-specific and knife-edge (v2.320), but that does not affect the dichotomy -- they fail
on DATA regardless. The cosmic-birefringence detection is itself ~3.6 sigma (tantalizing, not confirmed)
and its `beta -> g_R2_parity` map is order-of-magnitude (v2.321); a future null result would flip the data
axis (then the parity-even frameworks return and the constructed one's parity must shrink). The constructed
framework is a representative point (the v2.317 matter/curvature with parity 0.06 in the joint window), not
a unique optimum; what is shown is the EXISTENCE of a both-satisfying constructed theory, contrasted with
its NON-existence among the named ones. The other three data constraints (GW speed, dispersion, sub-mm)
are satisfied by all candidates here -- cosmic birefringence is the discriminating one. Toy basis, O(1)
prefactors.
