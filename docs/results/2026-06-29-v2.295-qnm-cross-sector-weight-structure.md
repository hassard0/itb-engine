# v2.295 - When does the shared spectrum bite? The cross-sector constraint as a function of w

## Question

FOURTH SLICE of the new-theory arc. v2.293 proposed the shared-spectral-density cross-sector principle
(with a calibrated ratio band); v2.294 found the rigorous 2x2 tilted-Hankel adds nothing. Is the whole
idea empty, or does the 3x3 / higher order rescue it -- and if not, what exactly does the shared
spectrum buy?

## Result (the question settled structurally, and the real content rescued)

**Structural negative (generalizes v2.294 to ALL orders).** The tilted measure `(1 + t w) dmu` has Hankel
matrix `H(t) = H_matter + t H_curv` -- a nonnegative combination of two PSD matrices (each a valid moment
Hankel). A nonnegative combination of PSD matrices is PSD, so `H(t)` is PSD for all `t >= 0` automatically
once both towers hold, AT EVERY MOMENT ORDER (verified numerically at 2x2 and 3x3). So the bare
shared-measure hypothesis -- `w >= 0` on a common support -- can NEVER add a cross-sector constraint; it
is exactly the two separate towers. v2.294's 2x2 negative was structural, not special.

**The rescue: stronger structure on `w` bites.** New information requires more than positivity of the
relative weight `w(M^2)`. The physically motivated statement -- a Regge-like tower, higher-mass states
coupling to curvature monotonically relative to matter -- is that `w` is MONOTONE. Then the ratios
`r_k = c_k/m_k = <w>_k` (x^k-weighted averages of one monotone `w`) are themselves monotone in `k`:

```text
  constructed weight   r = [r_0, r_1, r_2]        ratios monotone   both towers ok   tilted decomposes
  monotone  w          [0.425, 0.524, 0.603]      yes               yes              yes
  peaked    w          [0.617, 0.679, 0.634]      NO                yes              yes

  engine frameworks (r_k = [g_R2/g_4, g_R3/g_6, g_R4/g_8]):
    string_tree_eft    [0.400, 0.375, 0.281]   monotone (decreasing)
    asymptotic_safety  [0.375, 0.333, 0.222]   monotone
    cdt                [0.400, 0.375, 0.292]   monotone
    lqg_induced        [0.500, 0.667, 0.750]   monotone (increasing)
```

A PEAKED (non-monotone) weight, built from a valid positive measure, satisfies BOTH towers AND the
tilted-Hankel, yet has non-monotone `r_k` -- so it cannot come from a monotone shared weight. That is a
genuine constraint the towers miss. And the engine's frameworks all have monotone `r_k`, so they behave
exactly as if the shared spectral weight is monotone. All 5/5 checks pass.

```text
  cross-sector constraint as a function of the structure assumed on w:
    w >= 0           -> nothing new (the two separate towers)
    w monotone       -> ratio monotonicity r_k monotone (the genuine, premise-correct v2.293 content)
    w <= W (cutoff)  -> one-sided bracket: W m_k - c_k Hankel-PSD (uses the EFT cutoff scale W)
```

## What this establishes

The cross-sector arc is now closed cleanly and honestly. v2.293's ratio monotonicity was real after all,
but its correct premise is "w monotone", not "w >= 0"; v2.294 was right that the bare hypothesis is
empty; and v2.295 proves the emptiness is structural (the tilted-Hankel always decomposes) and pins the
genuine content to the assumed structure on `w`. The result is a clean map of where new cross-sector
theory can be extracted -- a definitive characterization, with the engine's frameworks all sitting in
the monotone-`w` class.

## Honest scope

Rigorous results: the tilted-Hankel decomposition `H(t) = H_m + t H_c` (hence "w>=0 adds nothing at all
orders") is an exact linear-algebra fact, verified at 2x2 and 3x3 on constructed positive measures. The
