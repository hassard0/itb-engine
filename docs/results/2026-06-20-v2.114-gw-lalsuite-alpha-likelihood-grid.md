## Method

The harness reuses the v2.113 LALSuite IMRPhenomD source-response templates, then
evaluates a fixed-event-parameter diagnostic likelihood:

```text
log L(alpha) = -0.5 || d - alpha_1 T_1 - alpha_2 T_2 ||^2
```

Grid settings:

```text
points_per_axis = 21
alpha_bar_1, alpha_bar_2 in [-2.0, 2.0]
network_grid_points = 441
```

This removes the v2.113 blocker:

```text
alpha_likelihood_grid_not_sampled
```
