## Method

The harness:

- extracts the same 4-second event-centered segment used in v2.108
- estimates an off-source Welch PSD from the 32-second public strain
- whitens the complex event FFT in the v2.110 source-backed frequency window
- builds complex first-order source-response templates as `delta_A + i delta_psi`
- projects the normalized whitened event spectrum onto those templates

This removes the v2.110 blocker:


## Interpretation

The source-backed alpha response now reaches a PSD-whitened complex event
spectrum estimated from public off-source strain. This is stricter than v2.110,
but it is still not a Liu-Yunes-style likelihood because the complex reference is
unit-normalized instead of a physical GR waveform, and event-parameter/systematic
uncertainties are not sampled.
