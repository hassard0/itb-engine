# v2.440 - the Emergent String Conjecture sharpens the candidate's UV completion into a clean geometric dichotomy: a heterotic-string tower XOR a Planckian-KK decompactification

Dreaming. The UV picture had stalled at a low-energy **degeneracy** (string ≈ CDT ≈ asymptotic safety, v2.436)
with a tower whose *existence* the amplitude confirms but whose *type* it cannot see (v2.437–438). This cycle
brings in a principle the engine had not used — the swampland **Emergent String Conjecture** (Lee–Lerche–Weigand
2019): *every* infinite-distance limit in a consistent quantum gravity's moduli space is either a
**decompactification** (a Kaluza–Klein tower becomes light) or an **emergent (heterotic) string** limit (a
fundamental string becomes tensionless) — no third option.

## The dichotomy

Applied to the candidate's multi-state tower (v2.438), the ESC forces:

```text
  the candidate's tower  =  heterotic-string tower   XOR   Kaluza-Klein tower
                            (=> string completion,          (=> decompactification
                             v2.434)                          to extra dimensions)
```

This is **sharper** than the low-energy degeneracy — it selects the two *geometric* towers — and, being a
swampland statement about the string landscape, it refines the *leading* (string) completion (v2.434).

## A concrete physical consequence: any extra dimensions are Planckian

The candidate's tower/species scale is **~0.8 M_Pl (Planckian)**. So on the KK branch, the extra-dimension size is
R ~ 1/Λ ~ **10⁻³⁴ m** — Planckian, *not* large: ~30 orders below the sub-millimeter gravity tests (Eöt-Wash
~5×10⁻⁵ m), hence **submm-invisible.** This is exactly consistent with the candidate satisfying the engine's
sub-mm-gravity constraint (had it required *large* extra dimensions, submm would have constrained it — it does
not). **So the candidate is *not* the large-extra-dimensions (ADD) scenario.** (5/5 checks.)

## What this establishes

Both ESC branches sit at the Planck scale, so the string-vs-KK discrimination *stays* the UV frontier (v2.437) —
but now as a **sharp, swampland-motivated, geometric dichotomy** rather than an open-ended degeneracy. The
candidate's UV completion, if swampland-consistent, is a **heterotic-string tower or a Planckian-KK
decompactification** — reconnecting v2.438 (a tower exists) to v2.437 (its type is the frontier) through a real
principle, and predicting any extra-dimensional branch is Planckian and submm-invisible.

## Honest scope

The ESC is a swampland **conjecture** (sourced_proxy tier) — well-supported in string examples, not proven. It
**presupposes the string landscape** (a QG with a moduli space), so it refines the *string* branch (v2.434) into
string-vs-KK — it does **not** engine-exclude the non-string alternatives CDT and asymptotic safety, which sit
outside its scope (a swampland statement can't rule out a non-geometric UV fixed point). Honest reading: *"if the
candidate is in the string landscape, its tower is heterotic-string XOR KK."* The tower scale (~0.8 M_Pl) is the
toy Dvali species proxy, so the 10⁻³⁴ m size is order-of-magnitude — the robust content is only that it's vastly
sub-submm (Planckian, not large), which holds across the feasible region. The ESC's "string" is specifically the
heterotic string, which *matches* v2.434 — a nice consistency, not an independent derivation. The submm
consistency is a real engine fact with a real interpretation (no large extra dimensions).
