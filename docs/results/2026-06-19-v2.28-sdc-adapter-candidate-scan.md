the distance, uncertainty, slope, normalization, and source metadata.

## Interpretation

v2.28 closes a code-path gap. A future framework can now implement:

```python
return sdc_tower_spectrum(
    tower_family="...",
    delta_moduli_mean=...,
    delta_moduli_sigma=...,
    lambda_sdc=...,
    normalization="...",
    source="...",
)
```

and the existing v2.24 readiness machinery will evaluate whether the prediction is
allowed, excluded, or overlapping the tower threshold.

The defensible claim is:

> The SDC adapter path is implemented and verified, but no current framework has supplied
> a sourced `Delta_moduli`. There are still no framework-level tower exclusions.
