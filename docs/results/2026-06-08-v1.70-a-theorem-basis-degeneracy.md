# v1.70 — The a-theorem in the toy basis: a constraint of new origin, no new information (and exactly why)

**Date:** 2026-06-08
**Compute:** Vulcan (16-core); physics derived with Dr. M. (Pluto).

---

## The question

I set out to add a *genuinely new* constraint of independent physical origin —
the **a-theorem** (Komargodski–Schwimmer 2011: in a 4d RG flow the Euler-density
Weyl-anomaly coefficient is monotone, a_UV ≥ a_IR). Everything in the stack so
far comes from forward dispersion, causality, holographic entropy, or swampland
distance/WGC arguments. RG-monotonicity is a *different* physical principle. If it
bites, it is information the engine did not already have.

## The physics (Dr. M.)

Dr. M.'s integrate-out derivation: when a heavy field of mass M is integrated
out, the coefficient of the Euler density (the Gauss-Bonnet / R²-type invariant,
= **g_R2** in our toy basis) picks up

        g_R2  ~  Δa / M⁴ ,     Δa = a_UV − a_IR.

So a-theorem monotonicity Δa ≥ 0 gives the clean **sign bound g_R2 ≥ 0**.
Implemented as `ATheoremMonotonicity` (class C), with 4 tests.

## The test — I did NOT assume the answer

The engine has **no standalone g_R2 ≥ 0 bound**: `graviton_mixed_positivity` is a
*two-sided* cap g_R2² ≤ g_4·g_6 (which permits negative g_R2), and
`cubic_curvature_positivity` only fixes g_R3 ≥ 0. So whether g_R2 ≥ 0 is new is a
real, open question. I searched a box that **deliberately includes negative g_R2**
(g_R2 ∈ [−0.5, 0.5], g_R3 ∈ [−0.2, 0.5], 81×81) at a string-like matter point, and
asked: *is there any point feasible under the existing corrected stack with
g_R2 < 0?* — i.e. a point the a-theorem would newly exclude.

| quantity | value |
|---|---|
| negative-g_R2 cells tested | 3240 |
| feasible under existing stack **with g_R2 < 0** | **0** |
| cells the a-theorem would newly exclude | **0** |
| framework verdicts changed | **0 / 5** |
| **verdict** | **REDUNDANT in this basis** |

Every single g_R2 < 0 point is *already* excluded. The "shadow enforcers" — the
existing constraints that kill them — are striking:

- `cemz_causality` — kills **all 3240**
- `quantum_focusing_conjecture` — kills **all 3240**
- `generalized_anomaly_inflow` — all 3240
- `cross_sector_efthedron` (3042), `graviton_forward_positivity` (3022)

So in this basis, **negative leading curvature coupling is forbidden by causality
and quantum focusing**, not by the a-theorem. The a-theorem arrives at a wall that
is already built.

## Why it's redundant — the real structural finding

This is not a null result, it is a *basis-resolution* result. The 4d Weyl anomaly
has **two** coefficients — a (Euler density) and c (Weyl²-squared). Both are
**curvature-squared** invariants. Our toy basis has only **one** curvature-squared
coupling, g_R2, so it **collapses a and c onto a single number**. RG-monotonicity
bounds (a-theorem Δa ≥ 0, and the Hofman–Maldacena conformal-collider bounds that
constrain the *ratio* a/c) therefore cannot carry information the single-coefficient
positivity bounds don't already encode: there is no second curvature-squared
direction for them to constrain.

**What would make it bite:** resolve the basis. Split the R²-sector into the Euler
invariant (∝ a) and an independent Weyl²-squared invariant (∝ c). Then:
- the a-theorem constrains the Euler coefficient's sign, and
- the Hofman–Maldacena bounds 1/3 ≤ a/c ≤ 31/18 become a genuine **two-sided wedge**
  on (Euler, Weyl²) — an upper bound on the Euler coupling relative to Weyl² that
  the current stack does **not** have (it caps |g_R2| only via g_4·g_6, and lower-
  bounds it only via forward positivity).

That is a concrete, falsifiable next frontier with a clear payoff, not a vague
"add more constraints."

## The honest headline

A constraint of genuinely independent *origin* (RG monotonicity) can still carry
zero independent *information* in a given basis — and the engine can now *prove*
that empirically and explain it structurally. The a-theorem doesn't shrink the
allowed region today; it tells us precisely which missing basis direction
(Weyl² ≠ Euler, i.e. c ≠ a) the engine would need to feel RG-monotonicity at all.
