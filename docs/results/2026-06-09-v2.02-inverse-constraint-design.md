# v2.02 — Inverse constraint design: which new bound would most shrink the consistent island?

**Date:** 2026-06-09
**Compute:** Vulcan (16-core; 1.5M-sample island).

---

## The inverse of constraint Jenga

v1.93 *removed* each constraint to rank irreplaceability. v2.02 *adds* hypothetical ones:
sweep candidate new half-space cuts `n·g ≤ c` and ask **which single new measurement
direction would most shrink the island while keeping the physically-favored data-driven
EFT**. Each direction's threshold is set **tangent at the data-driven EFT** (`c = n·g_dd`),
so the favored point is always retained; the shrinkage is the fraction of island beyond it.

## Result — the fattest directions are g_C (Weyl²) and g_8 (a blind spot)

The island (388 survivors of 1.5M) has **effective dimension 3.35** — confirming v1.73's
~3.4. Its principal components:

| PCA mode | dominant loading | island extent (std) |
|---|---|---|
| **PC1** | **g_C (Weyl²), −0.93** | **0.134** (fattest) |
| PC2 | g_8 (matter s⁴), −0.67 | 0.104 |
| PC3 | g_8 (+0.73) | — |

Ranked candidate new-bound directions by how under-constrained (fat) the island is:

| direction | island extent | shrinkage (keep favored) |
|---|---|---|
| **PC1 (≈ g_C / Weyl²)** | 0.134 | **74.5%** |
| single: g_C | 0.129 | 38% |
| PC2 (≈ g_8 / matter) | 0.104 | **94.6%** |
| **single: g_8** | 0.092 | 35% |
| a − c (g_R2 − g_C) | 0.087 | 33% |

- **The single fattest direction is the Weyl² coupling g_C** (PC1 loads −0.93 on it). A new
  bound on the Weyl² sector — a tighter conformal-collider / causality constraint on the
  central charge c — would shrink the island by **~75%** while keeping the data-driven EFT.
- **g_8 (the s⁴ matter moment) is the second-fattest single coefficient** — and it is
  exactly a **v1.88 blind spot** (no funded experiment). The PC2 cut along it removes
  **94.6%** of the island. The directions with *no current experiment* are precisely the
  directions along which the consistent island is *widest*.

## Cross-cycle coherence

This locks three results together:
- **v1.73** found the island ~3.4-dimensional with sloppy modes — here those modes are
  identified: **g_C (Weyl²) and g_8 (matter)**.
- **v1.88** flagged **g_8 and g_R3** as the blind spots (no probe) — confirmed here as the
  *fattest* island directions: the program is least-constrained exactly where it can't yet
  measure.
- **v1.98** showed **g_C (Weyl²)** drives holographic complexity (Euler being topological) —
  and g_C is *also* the least-constrained direction. **Bounding the Weyl² sector is doubly
  valuable**: it is both the leading complexity discriminator and the fattest island mode.

So the engine's own answer to "what to measure next" is: **a tighter Weyl²-sector bound**
(conformal-collider / causality on c) and a **high-moment matter measurement (g_8)** — the
sloppy modes and the funding gap are the same directions.

The consistent island (effective dim 3.35) is **fattest along the Weyl² coupling g_C and
the s⁴ matter moment g_8** — so a tighter **Weyl²-sector bound** (conformal-collider /
