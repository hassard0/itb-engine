## Honest global caveats (carried throughout)

1. **Toy O(1) constraint prefactors** — the realism program asks which conclusions
   survive a factor-~2; the central tension does (v1.80), the exact coordinates move.
2. **Order-of-magnitude cross-sector/messenger mappings** (κ_β, lam_map, ρ_inflow,
   BH-entropy factors) — the robust content is signs, orderings, and structure, not
   precise values.
3. **Cosmic birefringence is a ~3.6σ HINT**, not a discovery (polarization-angle
   systematics) — everything downstream inherits that.
4. **Screening is treated as a binary flag** — really density-dependent; "screened →
   evades sub-mm" is the optimistic bracket.
5. **CMB β is the axion–photon coupling while GW/PTA are axion–graviton** — linking
   them assumes one axion with comparable couplings; the cross-check tests that.
