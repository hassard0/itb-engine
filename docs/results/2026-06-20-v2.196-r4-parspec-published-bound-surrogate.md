## What Ran

The artifact takes the v2.191 ParSpec/qEFT source-package audit and the v2.195
source-event covariance export, then builds an event-aligned attachment packet.
It does not invent a posterior sample set. It records the public acquisition
surface and converts the published 90% qEFT upper bounds into a one-dimensional
`ell_qEFT_km` upper-limit surrogate.

The audited public surfaces are:

```text
arxiv_abs:
  https://arxiv.org/abs/2205.05132
  result = abstract_and_tex_source_available

arxiv_eprint_source_package:
  https://arxiv.org/e-print/2205.05132
  result = tex_and_pdf_figures_only

  https://doi.org/10.1103/PhysRevD.107.044030
  result = published_bounds_and_figures_only

public_web_search:
  result = no_public_machine_readable_samples_or_likelihood_found
```

The source package still has no detected machine-readable qEFT likelihood,
posterior-sample, covariance, or log-likelihood-grid file. The available public
material is TeX plus figure PDFs and published bounds.

## Malformed Control

The malformed packet corrupts the first surrogate quantile, marks the second
surrogate as a public likelihood, and removes the combined row. The evaluator
rejects it with:

```text

published_bound_surrogate_labels_mismatch
```

## Claim Boundary

The correct claim is:

```text
The engine has an event-aligned, nonclaiming published-bound surrogate on the
ParSpec qEFT source axis.
```

The incorrect claim would be:

```text
The engine has acquired public ParSpec/qEFT posterior samples or a claim-grade
R4 likelihood.
```

No framework exclusions are claimable from this artifact.
