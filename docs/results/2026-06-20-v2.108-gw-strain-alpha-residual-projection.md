## Method

The harness uses the v2.107 verified 32-second H1/L1 strain files, then:

- selects a 4-second event-centered window
- subtracts the local mean
- applies a Hann taper
- normalizes by tapered RMS
- projects the conditioned strain onto two orthonormal deterministic alpha proxy
  templates

The proxy templates are intentionally labeled:

```text
deterministic_proxy_not_source_backed_eft_waveform
```

## Interpretation

This is a real public-data wiring step: verified strain now flows through a
deterministic conditioning and projection pipeline. It is still not a
Liu-Yunes-style alpha likelihood. The next artifact must replace the proxy
templates with a source-backed cubic EFT waveform response for `alpha_bar_1` and
`alpha_bar_2`, then add PSD/calibration handling.
