## Honest scope

qualitative content), each item keeping its published caveat (β order-of-magnitude, η_B uncomputed, inflation
class-level, DE doesn't solve the CC magnitude). "Axiverse-available" is explicitly **not** a prediction — a
model-dependent possibility, so DM/H₀/strong-CP are compatibilities the candidate doesn't *forbid*, not things it
*explains*. The DM entry is the first record of the candidate's DM stance and uses the same axiverse-availability
logic as H₀/strong-CP (coherent with, partly repetitive of, that theme — the value is completing the accounting).
The scorecard doesn't uniquely pick this candidate (the cosmological items are class-level).
