# v2.359 - Observational fingerprints: each framework's signature across the three channels (and which channel discriminates)

## Question

The session built a three-channel falsifiability map (v2.356) and the program earlier scored frameworks on
theory+data (v2.322). Joining them: what is each named framework's *observational* signature in each channel,
and which channel actually discriminates the constructed theory from the community frameworks?

## Result (parity discriminates; screening is generic; ringdown orders)

```text
  framework            beta_pred  parity            ringdown floor   screening
  engine_constructed     0.204    consistent        0.042            must-screen
  pure_gr                0.000    excluded(beta=0)  0.000            no-fifth-force/ok
  string_tree_eft        0.000    excluded(beta=0)  0.112            must-screen
  asymptotic_safety      0.000    excluded(beta=0)  0.067            must-screen
  lqg_induced            0.272    consistent        0.300            must-screen
  cdt                    0.000    excluded(beta=0)  0.102            must-screen
```

All 5/5 checks pass. Three findings, one of which **tempers a session headline**:

1. **Parity is the unique discriminator.** Cosmic birefringence needs `g_R2_parity` in `[0.047, 0.153]`, so
   `beta = 0` excludes the four parity-even frameworks (pure_gr, string, AS, cdt); only the constructed
   theory and lqg are parity-consistent -- and lqg is theory-excluded elsewhere (v2.322), leaving the
   constructed theory uniquely consistent.
2. **Screening is GENERIC, not distinctive.** Every non-GR framework has `g_R2` above the unscreened cap
   0.063 (string 0.20, AS 0.15, cdt 0.22, lqg 0.30, constructed 0.19), so *all* require a screened R^2
   scalaron. Screening does NOT separate the constructed theory from the community frameworks. This honestly
   **tempers v2.354**: the screening mandate is real and falsifiable, but it is a generic feature of
   higher-derivative gravity with sizable `g_R2`, not a fingerprint of the constructed theory. (Only pure_gr
   escapes screening -- no R^2 term -- but pure_gr is parity-excluded.)
3. **Ringdown orders the frameworks.** The constructed theory has the mildest nonzero floor (0.042 vs
   AS 0.067, cdt 0.102, string 0.112, lqg 0.300), consistent with v2.336 -- a fingerprint, not yet an
   exclusion (no ringdown data).

## What this establishes

The constructed theory's observational distinctiveness lives **entirely in the parity channel**: its ringdown
is the mildest and its screening is generic. So the parity (birefringence) datum is not just the only binding
data constraint (v2.358) but the only channel that observationally *separates* the constructed theory from
the named frameworks.

## Honest scope

The fingerprints are exact arithmetic on the engine's encoded framework couplings, but those are the engine's
TOY encodings (e.g. "string_tree_eft" is the toy point, not the actual Veneziano coefficients), so the
per-channel numbers are relative statements among the engine's framework set, not literal predictions of real
string/AS/CDT/LQG. The `beta` map and Eot-Wash cap are the same toy/order-of-magnitude inputs as the
per-channel cycles. The parity exclusion of the parity-even four rests on the birefringence detection being
real (v2.329); if it is a systematic, `beta = 0` is allowed and the parity channel stops discriminating --
then NO channel separates the frameworks (screening is generic, ringdown has no data), a sharp statement of
how much rides on birefringence. The ringdown floors are coupling ratios, not sourced frequency shifts
(rank-1 map, v2.336). Toy basis, O(1) prefactors.
