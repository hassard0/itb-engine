For many cycles the exact string fingerprint was deferred as "forward-limit amplitude bookkeeping too error-prone."
Executed here for the **open string (Veneziano)**, where it is clean — a bold swing that paid off.

The Veneziano amplitude A(s,t) = Γ(−s)Γ(−t)/Γ(−s−t) (massless leading trajectory) has s-channel level-n forward
residue

```text
  Res_{s=n} A(s,t) = -(1/n!)(t+1)(t+2)...(t+n)   ->   at t=0:  -(n!/n!) = -1
```

So the **forward residues are exactly flat** (|r_n| = 1 for every n — the degree-n residue polynomial *telescopes*
to n!/n! = 1 at t=0, the spin sum collapsing forward). Verified numerically (r_n → 1). Therefore the forward
positivity moments are a_k = Σ_n 1/n^k = **ζ(k)** exactly, and the scale-clean low double-ratio is

```text
  (a_2 a_4)/a_3^2 = zeta(2) zeta(4)/zeta(3)^2 = 1.232
```

which the candidate's (g_4·g_8)/g_6² = **1.322 matches to ~7%** (the KK value 1.05 is far). 5/5 checks pass.
