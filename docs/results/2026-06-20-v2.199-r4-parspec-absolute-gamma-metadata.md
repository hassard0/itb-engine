## What Changed

v2.199 records a pinned, offline GWOSC preferred-parameter snapshot for the two
ParSpec source events:

| event | preferred PE record | final mass source | redshift |
|---|---|---:|---:|
| GW150914 | `gwtc1_pe_GW150914` | `63.1 +3.4/-3.0 M_sun` | `0.09 +0.03/-0.03` |
| GW200129 | `GWTC-3-confident_GW200129_065458_R2_pe_combined` | `60.2 +4.1/-3.2 M_sun` | `0.18 +0.05/-0.07` |

Sources:

```text
https://gwosc.org/api/v2/event-versions/GW150914-v3/parameters
https://gwosc.org/api/v2/event-versions/GW200129_065458-v1/parameters
```

The source relation preserved in v2.191 is:

```text
gamma = (ell_th c^2 (1 + z) / (G M_f))^p
p_qEFT = 6
```

Using `G M_sun / c^2 = 1.4766250385 km`, the implemented event-level form is:

```text
gamma = (ell_qEFT_km * (1 + z) / (M_f_source_solar * 1.4766250385 km))^6
```

## Combined Bound Handling

The published combined `ell_qEFT <= 51.3 km` bound is a joint event result. It
does not have one physical remnant mass/redshift pair. v2.199 therefore records
two projected rows, one through each source event's GWOSC metadata:

```text
GW150914 at combined bound: gamma = 0.046716000357
GW200129 at combined bound: gamma = 0.099723133671
combined_bound_single_remnant_metadata_ready = false
```

This prevents the combined bound from being misread as a single-event remnant
normalization.
