# v2.15 - Distance-prior variant: parity lobes reconnect when parity zeros are symmetry-protected

**Date:** 2026-06-19
**Compute:** local run plus Vulcan re-run against `phases_8d_1200.json`
**Stack:** default corrected stack, no-distance control, and parity-optional distance-prior variant

## Question

v2.14 showed that the four v2.13 parity lobes are split by the hard nonzero-threshold
encoding of `swampland_distance_conjecture`. This cycle asks whether the split survives
a minimal functional-form control:

1. remove the distance prior entirely;
2. replace it with a parity-optional distance prior that excludes symmetry-protected parity
   coefficients from the aspect-ratio denominator.

This does not assert the parity-optional prior is correct. It tests whether the topology
claim depends on the default prior's treatment of tiny parity coefficients.

## Command

```bash
python experiments/distance_prior_variants.py \
  --input experiments/results/v2.13/phases_8d_1200.json \
  --out experiments/results/v2.15/distance_prior_variants.json \
  --samples 101
```

## Result

| stack variant | lobes reach parity zero | parity-zero plane connected | all lobes connected by parity-zero detour |
|---|---:|---:|---:|
| default | no | yes | no |
| no distance prior | yes | yes | yes |
| parity-optional distance prior | yes | yes | yes |

Under the default stack, all four lobe-to-zero descents fail first on:

```json
{"swampland_distance_conjecture": 4}
```

Under both controls, the parity-zero detour connects all four lobes. Direct centroid-to-
centroid lines still graze `t_hooft_anomaly_matching` for two pairs, with margins around
`-4.4e-4` and `-3.1e-4`, but the multi-segment path

```text
lobe centroid -> parity-zero projection -> parity-zero projection -> other lobe centroid
```

is feasible.

## Interpretation

The four-lobe topology is **not robust** to the most obvious distance-prior functional-form
control. It is controlled by whether parity coefficients are allowed to pass continuously
through zero.

This supports the v2.14 correction:

> The current four-lobe topology is an encoding artifact of the distance hierarchy prior,
> not a discovered phase structure of quantum gravity.

The parity sector can still be physically important. The point is narrower: current
straight-line topology cannot be used as evidence for four disconnected parity phases.

## Consequence for the research program

The next load-bearing task is not more sampling. It is a better Distance Conjecture proxy:

- continuous at zero coefficients,
- explicit about which zeros are symmetry protected,
- derived from a moduli/tower model rather than coefficient aspect ratio alone,
- tested against Jenga, near-miss, island census, and topology again.

Until then, any result whose main gatekeeper is `swampland_distance_conjecture` must be
phrased as a result under the current hierarchy prior, not as a generic swampland verdict.

## Bottom line

The distance-prior variant reconnects the four parity lobes. This is a strong negative
result against the topology claim and a useful pointer to the engine's next bottleneck:
the Distance Conjecture needs a continuous, physically motivated encoding before topology
or framework exclusions can be considered robust.
