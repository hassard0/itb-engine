# v2.09 — The thematic taxonomy: a navigable map of the program

**Date:** 2026-06-09

---

## Why

After 118 result notes spanning v0.8 → v2.08, the chronological [INDEX](INDEX.md) is no
longer the easiest way in. v2.09 adds a **thematic map**: `tools/taxonomy.py` reads every
note, assigns it to one of **9 themes** by transparent keyword rules, and writes
[**TAXONOMY.md**](TAXONOMY.md) — notes grouped by theme, each theme summarised, plus a
*theme × era* table showing how the program's focus shifted.

## The map

| theme | notes |
|---|---|
| Foundations & basis | 31 |
| Empirical swampland & data ingestion | 30 |
| Meta-experiments & auditing | 13 |
| Forecasts & experiment design | 13 |
| Synthesis & reports | 10 |
| Holographic observables | 9 |
| Data-driven EFT & the central tension | 6 |
| The consistent island | 5 |
| Inflation & cosmology | 1 |

The **theme × era** table makes the arc legible: **foundations** dominate v0.8–v1.5; the
**empirical swampland** opens up at v1.69–v1.85 (data ingestion); and **meta-experiments**
(auditing the engine) cluster in v1.86–v2.10 (8 of 13). The program moved from *building*
the constraint structure → *confronting* it with data → *auditing* what it had built.

## Honest scope

Keyword clustering is heuristic — a **navigation aid, not analysis**. Two large catch-all
themes (Foundations, Empirical swampland) absorb borderline notes; the assignment rules are
transparent in `tools/taxonomy.py` and re-runnable. The optional timeline figure is
generated where matplotlib is available.

## What's committed

- `tools/taxonomy.py` — the note parser + keyword theme-assigner + `TAXONOMY.md` generator
  (+ optional timeline figure).
- `docs/results/TAXONOMY.md` — the generated thematic map (118 notes, 9 themes, era table).
- `tests/test_taxonomy.py` — 3 tests (assignment returns a valid theme; data/meta keywords
  route correctly; the partition is exhaustive — every note in exactly one theme).
- TAXONOMY.md linked from the README and FINDINGS.

## Headline

A `tools/taxonomy.py` clusters the program's **118 result notes into 9 navigable themes**,
and the theme × era table tells the story in one glance: **build the structure (v0.8–v1.5)
→ ingest the data (v1.69–v1.85) → audit the engine (v1.86–v2.10)**.

## Reproducibility

```bash
python tools/taxonomy.py        # regenerates docs/results/TAXONOMY.md
pytest tests/test_taxonomy.py -q
```
