## Method

The harness keeps the v2.111 off-source PSD whitening, then replaces the unit
complex reference with a leading-order GR stationary-phase inspiral reference:

```text
h_GR(f) proportional to f^(-7/6) exp(i * 3/(128 eta) * v_f^(-5))
```

It then builds first-order source-response templates:

```text
delta h_alpha(f) = h_GR(f) * (delta A_alpha(f) + i * delta psi_alpha(f))
```

This removes the v2.111 blocker:

```text
unit_gr_reference_not_physical_waveform
```
