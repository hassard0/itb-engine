## Acceptance Gate

A claim-grade public likelihood packet must include all of:

```text

ell_qeft_or_qnm_axis_schema
source_event_rows_or_combined_policy
prior_and_threshold_policy
waveform_sampler_version_metadata
calibration_and_systematics_policy

```

The current candidate satisfies none of those criteria because no released
machine-readable likelihood object was found.

## Roadmap From Here

The next research run should choose one of three paths:

```text
1. Find or derive a source-backed qNM-to-Bresciani sensitivity matrix.
2. Build a reproducible qEFT likelihood rerun packet with public GWOSC data,
   priors, waveform/sampler versions, calibration policy, hashes, and tests.
3. Use pyRing/LALSuite in runtime coordinates for a nonclaiming likelihood
   rerun, while keeping the Bresciani operator-map gate closed.
```

Any promoted discriminator still needs a full-rank source-backed map, a real
likelihood export, claim-grade systematics, remote Linux reproduction, and
external adversarial review.
