# v2.377 - SWING (forward test): next-generation birefringence discriminates WHICH consistency principle the parity sector obeys

## Question (capping the parity-determination arc)

The parity coupling has several determinations (geometric center, anomaly-saturated v2.370, anomaly-closed
v2.371, feasibility-ceiling v2.360). Do they make a *next-generation birefringence measurement* a discriminator
of the theory's own internal consistency structure -- not just theory-vs-GR?

## Result (an ordered hierarchy, discriminable at ~4x better precision)

```text
  determination         g_R2_parity   beta_pred    vs measured 0.34 +/- 0.09
  geometric_center        0.060        0.204 deg    1.51 sigma below
  anomaly_closed_system   0.065        0.222 deg    1.31 sigma below   (both anomaly matchings exact, cubic != 0)
  anomaly_saturated       0.078        0.266 deg    0.82 sigma below   (inflow exact, cubic = 0)
  feasibility_ceiling     0.091        0.309 deg    0.34 sigma below   (no anomaly determination)

  variant spread: 0.105 deg;   anomaly fork (saturated vs closed): 0.044 deg
  precision to resolve the fork: ~0.022 deg   (current ~0.09 deg)
```

All 5/5 checks pass. The four determinations form an ordered hierarchy, all *below* the current central value,
unresolvable at today's 0.09 deg precision -- but the **spreads are the prediction**.

## What this establishes

The same birefringence observable that established the parity headline (excluding `beta = 0`) becomes, at
next-generation precision, an **internal test of the theory's UV consistency structure**:
- separating **anomaly-saturated (0.266) from anomaly-closed (0.222)** tests whether the parity-odd **cubic** is
  present -- the v2.371 fork -- and needs only ~0.02 deg precision;
- separating any **anomaly determination (0.22-0.27) from the feasibility ceiling (0.31)** tests whether the
  parity magnitude is **anomaly-determined** or merely sits at the theory's consistency edge toward the data.

So a birefringence measurement an order of magnitude sharper than today's ~0.09 deg -- reaching ~0.02-0.03 deg
-- would resolve *which consistency principle the parity sector obeys*: is anomaly matching saturated? is the
cubic present? is the theory anomaly-determined or ceiling-limited? That turns the parity channel into a probe
of the theory's anomaly structure -- the sharpest testability statement the parity sector supports, and a
genuine forward-looking use of the observable.

## Honest scope

The four variant `beta` predictions are exact given the engine's parity determinations, but each inherits that
variant's scope: the anomaly values scale with the toy prefactors `rho`, `rho_match` (v2.344), the ceiling is a
sampled feasibility bound (v2.360), and ALL use the toy birefringence map `beta = 3.4 deg * g_R2_parity`, so
the *absolute* beta values are toy-basis (an O(1) re-normalization shifts them together). The ROBUST content is
the ORDERING and the RELATIVE spreads (anomaly-saturated > anomaly-closed by ~0.02 deg because the cubic eats
budget; all below the central), which are structural. "Required precision ~0.02 deg" is a derived statistical
spread (half the fork), **not** a claim about any specific instrument's forecast sensitivity -- whether a real
experiment reaches it is an observational question not answered here (next-gen CMB birefringence is broadly in
this regime, but that is context, not a sourced number). Presumes the birefringence detection is real (v2.329)
and the sign is separately data-set (v2.364). Toy-basis absolute values, structural ordering/spreads.
