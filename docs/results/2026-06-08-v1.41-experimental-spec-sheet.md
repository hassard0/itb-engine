## 1. Sub-mm gravity — the decisive discriminator

The R²-scalar Yukawa deviation from Newton, δ(r) = −(1/3) e^(−r/λ_Y), with λ_Y
from each theory's g_R2 at the dark-energy cutoff (v1.40). Scanning the
separation to maximize pairwise separation gives the optimal probe distance:

**Best discriminating separation: r\* = 93 µm.** Fractional-force deviation there:

| theory | λ_Y | δ(93 µm) / Newton |
|---|---|---|
| discovered_parity_violating | 127 µm | **−15.97 %** |
| LQG-induced | 110 µm | −14.32 % |
| CDT | 95 µm | −12.43 % |
| discovered_high_g8 | 92 µm | −12.15 % |
| string tree-EFT | 90 µm | −11.85 % |
| asymptotic safety | 78 µm | −10.09 % |
| discovered_novel | 74 µm | −9.51 % |

The deviations are **10–16 % of the Newtonian force** — a large, unmissable
signal (if the cutoff is at the dark-energy scale). Discrimination requirements:

| precision (fractional force) | pairs resolved (of 21) | apparatus |
|---|---|---|
| 1 % | **14 / 21** | current torsion balance |
| 0.1 % | **21 / 21** | next-generation |
| 0.14 % | all pairs (threshold) | — |

**A sub-mm gravity measurement at 93 µm to ~1 % force precision — achievable
today — already distinguishes two-thirds of the candidate quantum gravities;
0.1 % distinguishes all of them.** The theories with larger g_R2 (the
parity-violating branch, LQG) give the biggest deviations and are the easiest
targets.

## 2. Gravitational birefringence — the parity sector

The parity-violating candidates sit just below the current LIGO O3 bound
(|g_R2_parity| ≲ 0.1):

| theory | \|g_R2_parity\| |
|---|---|
| discovered_parity_violating | 0.092 |
| LQG-induced | 0.080 |
| discovered_high_g8 | 0.033 |
| discovered_novel | 0.021 |
| string / AS / CDT | 0 |

Flagging the parity branch needs birefringence sensitivity **|g_R2_parity| ~ 0.011
— ~10× below LIGO O3.** Within reach of LIGO O5 / next-generation GW detectors.
A detection here (with the v1.37 cubic-suppression structure) would be the
smoking gun for the consistent parity-violating theory; combined with v1.37, it
also pins the swampland anomaly coefficient ρ.

## 3. GIE — the foundational gate

Existence threshold (phase > 1): µg masses, ~10 µm superposition, ~1 s coherence,
P < 10⁻¹⁷ Torr, T < 100 mK (Dr. M.). Answers *is gravity quantum* (validates the
whole feasible region), not *which* — the sub-mm Yukawa does the discriminating.

## Honest hinge (unchanged, stated as the directive)

All of §1–2 assumes the gravitational cutoff sits near the dark-energy scale
(λ ~ sub-mm). That is a strong assumption — but it is the *motivated* one (the
cosmological-constant length) and the one short-range experiments already probe.
If instead Λ is Planckian, only the GIE yes/no is accessible. Either way the
directive is sharp: **look at 70–130 µm.**
