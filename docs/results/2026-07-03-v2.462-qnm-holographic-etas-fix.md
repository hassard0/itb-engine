# v2.462 - holographic bug-fix: the η/s observable was a factor-of-2 error (1−8λ), corrected to the Brigante 1−4λ

Examining the holographic sector (off the axion/dark-energy track) surfaced a genuine internal inconsistency — the
candidate's shear-viscosity "prediction" η/s was implemented **two different ways**:

```text
  src/itb/holographic_ac.py:            eta/s = (1/4pi)(1 - 4 lambda_GB)   CORRECT (Brigante et al 2008; its docstring even states the 16/25 floor)
  src/itb/gravitational_observables.py: eta/s = (1/4pi)(1 - 8 lambda_GB)   WRONG (factor of 2; also mis-stated the floor as 0.28 instead of 16/25=0.64)
```

The two disagreed on the candidate's value (g_R2 ~ 0.19): the wrong (1−8λ) gave η/s ~ 0.665, the correct (1−4λ)
gives η/s ~ 0.833 — and ~0.83 is the value the summary always quoted (~0.81), so `gravitational_observables` was
the **outlier error**. Fixed it to 1−4λ (predict + jacobian + docstring + causality floor), consistent with
`holographic_ac.py` and Brigante; updated the two hard-coded test assertions. 5/5 checks pass, 22 holographic-
dependent tests pass.

## After the fix (verified)

```text
  candidate g_R2 = 0.19  ->  eta/s = 0.833 KSS-units  (KSS-violating, < 1; holographic_ac module agrees)
  largest g_R2 = 0.40    ->  eta/s = 0.648            (at the Brigante causality floor 16/25 = 0.64)
```

The two modules now agree, and the largest coupling correctly saturates the famous 16/25 KSS-violation floor.

## Honest scope

A **code / physics-consistency fix**, not a new prediction. The η/s observable remains a holographic **portrait**:
it assumes the candidate has a Gauss-Bonnet AdS/CFT dual — *not* established (the candidate is a flat-space EFT);
`holographic_ac.py` already flags this as a what-if. The `lam_map = 0.22` (g_R2 → λ_GB) is an order-of-magnitude
toy map, so the specific 0.833 is toy-normalized; the robust content is the **ordering** (larger g_R2 ⇒ lower η/s)
and the **KSS-violating sign** (η/s < 1/4π for g_R2 > 0), not the precise number. The fix touches an *observable*
output, not a *constraint*, so the candidate / feasible region is unaffected — only the reported η/s changes
(0.665 → 0.833). This is the kind of latent internal error the honest-scrutiny discipline is meant to catch:
cross-checking two modules against the published Brigante result exposed a factor-of-2 bug.
