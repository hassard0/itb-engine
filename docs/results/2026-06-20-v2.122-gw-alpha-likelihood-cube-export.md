## Method

The harness reruns the v2.115 LALSuite IMRPhenomD likelihood construction on
Vulcan with the optional `lalsuite` wheel installed. For each detector it exports
the full matrix:

```text

nuisance points per detector = 81
alpha grid points = 441
total likelihood cells = 71442
```

The exported cube is checked by reconstructing the v2.115 network marginal and
profile likelihood surfaces from the per-nuisance matrices.

## Interpretation

The missing prior cube blocker is removed. The cube exactly reconstructs the
previous v2.115 marginal/profile surfaces, so it is the right input for actual
nuisance-prior sweeps over total mass, eta, coalescence time, and phase. Prior
sensitivity remains open until those physically justified reweightings are run.
