# v2.264 - The Dvali species scale: how many light fields lower the quantum-gravity cutoff

## Question

Completes the swampland sub-arc (v2.254 Weak Gravity, v2.255 Distance Conjecture, v2.263 TCC). In a
theory with `N` light species, is the scale where gravity becomes strong really the Planck mass -- or
is it lowered? And does that cutoff structure tie the swampland conjectures together?

## Result

The quantum-gravity cutoff is the **Dvali species scale** `Lambda_sp = M_Pl / sqrt(N)`, below Planck.
Two independent arguments fix it and agree on the `-1/2` exponent:

- **Black-hole entropy** (exact): the smallest semiclassical BH has radius `1/Lambda` and entropy
  `S = (M_Pl/Lambda)^2`; resolving `N` species needs `S >= N`, so `Lambda <= M_Pl/sqrt(N)`, and at the
  species scale the BH entropy is *exactly* `N` (verified for every grid point).
- **Perturbative unitarity / running Newton constant**: `N` species renormalize the graviton kinetic
  term `M_Pl,eff^2 ~ N Lambda^2`, hitting strong coupling at the same `Lambda ~ M_Pl/sqrt(N)`.

**The Standard Model's ~118 light dof already lower gravity's true cutoff to `~0.09 M_Pl ~ 2e17 GeV`**
-- about an order of magnitude below Planck. Reaching a **TeV** cutoff (large extra dimensions / ADD)
needs `N ~ 1e31-1e32` species -- **reproducing the famous ADD count**, because the species scale *is*
the ADD fundamental gravity scale.

## What this establishes

The species scale closes the swampland web: a Distance-Conjecture light tower (v2.255) makes `N` grow
with field distance, so `Lambda_sp` drops below `M_Pl` exactly as the EFT-breakdown picture demands.
The Weak Gravity Conjecture (v2.254), the Swampland Distance Conjecture (v2.255), the
Trans-Planckian Censorship Conjecture (v2.263) and the species scale are one interlocking structure --
all statements about where and how the gravitational EFT cuts off. The `-1/2` exponent is a
prefactor-free, BH-entropy-fixed robust prediction.

## Honest scope

`Lambda_sp = M_Pl/sqrt(N)` is the standard Dvali result; the `-1/2` exponent is robust (fixed by BH
entropy), but the `O(1)`-`O(4pi)` PREFACTOR is convention-dependent (the BH argument gives 1, the
loop-running argument carries a `4pi`), so the absolute cutoff is order-of-magnitude. The SM `N~118`
is the count of light degrees of freedom, itself a representative `O(100)` number (depends what counts
as light). The ADD count differs `~25x` between the reduced and full Planck-mass conventions (both
reported). The SDC tie-in uses the v2.255 tower `m/M_Pl = exp(-alpha dphi/M_Pl)` with `alpha~O(1)`;
the precise `N(dphi)` law (KK vs string tower) is model-dependent, so the field-distance map is
illustrative of the direction, not an exact prediction. A QG-consistency / cutoff-structure result,
not an engine constraint refit.
