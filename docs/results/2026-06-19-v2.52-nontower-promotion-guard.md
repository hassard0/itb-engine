# v2.52 - Non-tower promotion guard: internal cuts cannot become claims

## Question

v2.49, v2.50, and v2.51 left three non-tower routes alive but non-claimable:

- cosmic birefringence is an external hint, but systematics and the engine's toy axis mapping remain open;
- `g_C/g_8` island geometry is robust, but internal cuts are not measurements;
- `g_C/g_8` observables are source-backed in theory, but have no external numerical measurement route ready for framework exclusion.

This loop turns that claim posture into code. It adds a reusable `ExternalMeasurementEvidence` contract and a non-tower promotion guard.

## What Was Added

- `src/itb/nontower.py`
  - `ExternalMeasurementEvidence`
  - `validate_external_measurement_evidence`
  - `evaluate_nontower_promotion_guard`
- `experiments/nontower_promotion_guard_audit.py`
- `tests/test_nontower_promotion_guard.py`
- Artifact: `experiments/results/v2.52/nontower_promotion_guard_audit.json`

## Guard Rule

A non-tower route can be promoted only if all of the following are true:

- source URL is primary or DOI-backed;
- source type is valid;
- measurement kind is external numeric data, detection, or upper bound;
- numerical value and uncertainty are present;
- axis mapping is source-backed direct or a validated framework adapter;
- systematics are closed or bounded;
- discriminator math is actually excluding;
- the row is not merely an internal island cut.

## Result

The audit has 8 scenarios:

| class | count |
|---|---:|
| current blocked routes | 7 |
| synthetic claim-ready fixture | 1 |
| current claim-ready routes | 0 |

Blocked current routes:

- six `g_C/g_8` sourceability routes from v2.51;
- the ACT DR6 birefringence hint.

The synthetic fixture proves the positive path: when external numerical evidence, source-backed axis mapping, closed systematics, and excluding math are all present, the status becomes:

```text
non_tower_discriminator_claim_ready
```

Every current route remains:

```text
non_tower_promotion_guard_blocked
```

## Interpretation

The engine now has the same kind of claim discipline for non-tower routes that v2.41-v2.48 built for tower routes. This does not solve quantum gravity, but it prevents the next likely error: promoting a PCA cut, structural holographic bound, or sub-discovery birefringence hint into a framework exclusion.

## Current Blockers

Across current rows, the common blockers are:

- `external_measurement_evidence_not_ready`
- `discriminator_math_not_excluding`
- `systematics_not_closed`
- `missing_external_numeric_measurement`
- `measurement_kind_not_external_numeric`
- `axis_mapping_not_source_backed`
- `internal_cut_not_external_measurement`

The birefringence hint is useful because it already has a numerical value and uncertainty, but the guard still blocks it on source-backed axis mapping, systematics, and non-excluding math.

## Next Loop

Use this guard to build a unified discriminator status matrix across tower and non-tower routes:

- tower route: native-adapter evidence gates;
- birefringence route: external-data/systematics gates;
- `g_C/g_8` route: external-measurement-readiness gates.

The goal is a single frontier table where every route has a status, blocker, and next required artifact.
