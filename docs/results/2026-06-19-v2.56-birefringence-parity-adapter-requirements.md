# v2.56 - Birefringence parity adapter requirements: beta is alive, the engine map is not

## Question

v2.49 kept cosmic birefringence empirically alive, and v2.52/v2.53 blocked it on
systematics and source-backed axis mapping. This audit makes the mapping blocker
explicit: an observed CMB polarization rotation `beta` is not yet a
source-backed engine value for `g_R2_parity` or `g_R3_parity`.

## Adapter Requirements

A promotable birefringence route must provide:

| requirement | current status | blocker |
|---|---|---|
| source-backed operator identity | missing | `operator_identity_not_source_backed` |
| beta-to-engine-axis normalization | toy only | `beta_axis_normalization_toy` |
| EM versus gravitational parity separation | missing | `em_gravity_parity_map_not_separated` |
| frequency/redshift transfer model | missing | `missing_frequency_redshift_transfer` |
| public beta likelihood or covariance | missing | `missing_public_beta_likelihood` |
| absolute angle calibration closure | open | `instrument_angle_miscalibration_degeneracy` |
| foreground systematics closure | open | `foreground_systematics_not_closed` |
| discovery-grade or preregistered subclaim handling | sub-discovery | `no_5sigma_single_dataset_detection` |
| non-circular framework predictions | open | `data_driven_eft_reuses_birefringence` |
| excluding discriminator math | missing | `discriminator_math_not_excluding` |

The current evidence row has a numerical beta and uncertainty, so it passes that
part of the non-tower guard. It still fails promotion on:

- `axis_mapping_not_source_backed`
- `systematics_not_closed`
- `discriminator_math_not_excluding`
- `external_measurement_evidence_not_ready`

## Interpretation

The beta hint is useful, but it cannot be used as a framework discriminator
until the map from observed CMB rotation to engine parity coefficients is
source-backed and non-circular. The data-driven EFT currently tracks beta by
construction, so the same beta measurement cannot be used as both construction
input and validation target.

The next useful artifact is a source-backed beta-to-parity adapter with public
likelihood, closed calibration/foreground systematics, and framework predictions
computed independently of the beta input.
