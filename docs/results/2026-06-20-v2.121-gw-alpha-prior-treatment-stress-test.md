## Method

The harness loads the v2.120 packet and the v2.115 network alpha likelihood
grid. It sweeps a profile-temperature path between the saved marginal
likelihood and saved profile likelihood:

```text
combined_logL = (1 - t) * logL_marginal + t * logL_profile
t in {0.0, 0.1, 0.25, 0.5, 0.75, 1.0}
```

This is not a physical nuisance-prior posterior. It is a stress test over the
two endpoint surfaces that were persisted in v2.115.

## Interpretation

The saved marginal/profile summaries are enough to reject a prior-sensitivity
closure claim. The alpha optimum moves by more than one alpha-axis grid step
once profile weighting enters. The next fix is not another summary proxy: the
engine needs the detector-by-detector alpha/nuisance likelihood cube before
marginalization, so physically justified priors over mass, eta, coalescence
time, and phase can be swept directly.
