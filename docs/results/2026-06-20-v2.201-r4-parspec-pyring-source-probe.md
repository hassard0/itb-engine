## What Changed

v2.201 makes the public pyRing source fragment executable and hash-pinned. The
artifact records the public `EFT_QNMs` branch:

```text
repo = https://git.ligo.org/lscsoft/pyring
branch = EFT_QNMs
branch_head_sha = 01b7f797c6a260962a1662c4e3450ccfbf48653f
tree = https://git.ligo.org/lscsoft/pyring/-/tree/EFT_QNMs/pyRing/data/NR_data
```

The six quartic table files are:

```text
EFT_coefficients_quartic_1_minus.txt
EFT_coefficients_quartic_1_plus.txt
EFT_coefficients_quartic_2_minus.txt
EFT_coefficients_quartic_2_plus.txt
EFT_coefficients_quartic_3_minus.txt
EFT_coefficients_quartic_3_plus.txt
```

Each table has three mode rows:

```text
(2,2,0), (2,2,1), (3,3,0)
```

and the schema:

```text
l, m, n, om_r_0..om_r_12, om_i_0..om_i_12
```

The pyRing runtime source uses `om_r_i` as frequency-shift spin-polynomial
coefficients and applies a sign flip to `om_i_i` for the imaginary-frequency
convention:

```text
df_EFT_coeffs[theory] = om_r_i
domi_EFT_coeffs[theory] = -om_i_i
```

## Source Rank Probe

The artifact builds a local spin-zero QNM coefficient matrix for modes
`(2,2,0)` and `(2,2,1)`:

```text
rows = domega_220_n0_spin0,
       domi_220_n0_spin0_pyring_sign,
       domega_221_n1_spin0,
       domi_221_n1_spin0_pyring_sign

columns = quartic_1_minus, quartic_1_plus,
          quartic_2_minus, quartic_2_plus,
          quartic_3_minus, quartic_3_plus

rank = 4
```

That proves the checked pyRing tables contain useful machine-readable QNM
coefficient information. It does not prove that there are six independent
operator axes. The plus/minus columns are QNM mode-splitting branches for a
selected EFT theory, not independent Wilson or Bresciani axes.

The correct claim is:

```text
The public pyRing EFT_QNMs branch supplies hash-pinned quartic QNM coefficient
tables that can seed a future source-backed sensitivity derivation.
```

The incorrect claim would be:

```text

claim-ready ParSpec/qEFT likelihood.
```
