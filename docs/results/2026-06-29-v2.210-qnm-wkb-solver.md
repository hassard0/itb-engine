# v2.210 - First-principles WKB quasinormal-mode solver (validated)

## Question

v2.209 established that no public source supplies a full-rank operator->QNM sensitivity
for the R4 ringdown route -- the parity-odd axis is dark and the published analyses are
rank-1 per parity-even theory. A standing roadmap option is to stop waiting for a
literature map and instead **compute the QNM sensitivity in-house**. The prerequisite is
a from-scratch QNM solver, validated against general relativity. Can the engine compute
black-hole ringdown frequencies from a perturbation potential alone, accurately enough to
be useful, with no external QNM library?

## Result

Artifact: `experiments/results/v2.210/qnm_wkb_solver.json` (computed on Vulcan, 16-core
Linux; reproduces identically with the local venv).

A 3rd-order Iyer-Will WKB solver, fed the exact Regge-Wheeler potential and its
tortoise-coordinate derivatives (Fornberg finite differences), reproduces the canonical
Schwarzschild gravitational quasinormal modes (M=1, G=c=1):

```text
omega_220 = 0.373162 - 0.089217 i   ref 0.373672 - 0.088962 i   rel.err 1.5e-3
omega_221 = 0.346016 - 0.274914 i   ref 0.346711 - 0.273915 i   rel.err 2.8e-3
```

i.e. the fundamental l=2 mode to **0.15%** and the first overtone to **0.28%** -- the
standard accuracy of 3rd-order WKB for the low-lying modes. The reference values are the
Berti-Cardoso-Will tabulated QNMs; the solver uses only the potential, no QNM library.

## What Changed

The engine now has an **in-house black-hole-spectroscopy capability**: given any
perturbation potential V(r) it returns the ringdown QNM frequency omega = omega_R +
i omega_I from the WKB peak expansion. Two pieces:

```text
schwarzschild_qnm(n)           -> validated GR modes (omega_220, omega_221)
qnm_potential_sensitivity(dV)  -> d(omega)/d(eps) for V -> V + eps dV
```

The sensitivity function is the operator->QNM machinery the R4 route needs. As a
demonstration, a representative short-range (dimension-8-like) deformation
`delta_V = f(r)/r^6` near the photon sphere gives a finite ringdown response:

```text
d(omega_R)/d(eps) = +4.0e-4
d(omega_I)/d(eps) = +5.2e-4
```

So a higher-derivative modification of the Regge-Wheeler potential maps to a concrete
(frequency, damping) shift. **Plugging the physical R4 quartic-operator delta_V into this
function yields the engine's own operator->QNM sensitivity** -- the relation v2.209 found
to be unsourceable at full rank from the literature. This converts the R4 blocker from
"wait for a published map" into "derive the modified potential, then compute."

## Honest Scope

- 3rd-order WKB is ~0.1-1% for n=0,1 and degrades for high overtones and near-extremal
  cases; it is the standard tool for EFT-corrected-potential QNMs but is not Leaver-grade
  precision. Higher WKB order (6th, Pade-resummed) is a future upgrade.
- The validated result is for the GR Regge-Wheeler potential. Using it to constrain R4
  still requires the **physical** modified potential for the quartic operators (the
  parity-even sector is computable; the parity-odd axis remains dark, v2.209), plus
  claim-grade systematics and external review before any framework claim.
- The sensitivity demonstration uses an illustrative delta_V shape, not the physical R4
  operator potential.
