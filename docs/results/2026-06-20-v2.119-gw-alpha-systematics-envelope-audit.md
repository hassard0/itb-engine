## Method

The harness loads existing results and computes four proxy envelopes:

- waveform: leading-order GR projection versus LALSuite IMRPhenomD projection
- detector calibration: H1/L1 projection spread proxy
- prior sensitivity: marginal best point versus profile best point
- EFT truncation: next-PN-power proxy `v_f_max^2`

These are quantitative diagnostics, not calibrated systematics bounds.
