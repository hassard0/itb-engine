## What this says

The experimental program the engine designed **would actually work by ~2030**:
projected DESI/Euclid + LIGO O5 + CMB-S4 + next-gen torsion-balance data would
decisively identify the true theory among the candidates. The discrimination
comes from the complementary handles the program mapped:

- **parity (g_R2_parity)** — handedness + magnitude cleanly separates LQG (+0.08),
  the discovered PV branch (−0.092), and the parity-conserving set;
- **matter g_8** — separates the low-g8 novel branch and the high-g8 branch from
  the mid-g8 catalogued frameworks;
- **Yukawa g_R2 + cubic g_R3** — pin the remaining directions;
- only **string ↔ CDT** survive as a near-degenerate pair (Δg_R2 = 0.02, below the
  projected sub-mm resolution).

This is the optimistic, falsifiable payoff of the whole 2026-06 program: not just
"here are the theories and the experiments," but **"here is when we will know" —
~2030, at ≥87% confidence for any candidate, with string/CDT the one pair needing
a further push.**

## Honest limitations

The projected sensitivities are assumptions (chosen to be realistic for the named
facilities, not quoted from forecasts); the gravitational-channel sensitivities
assume the dark-energy-scale cutoff so the signals are in reach (v1.44 hypothesis).
Framework coefficients are point-values (no per-framework uncertainty), so the
100%s would soften under the v1.25 coefficient-uncertainty bands — the
qualitative result (clean ID except string/CDT) is robust. w₀ is not used for
framework ID (it tests the dark-energy axion, not the Wilson-coefficient point).
