## Interpretation

The recheck adds a relevant 2025 partial-wave unitarity formalism, but it does
not change the route status. The `g_8` path still lacks the same hard artifact:
an external numerical measurement with a source-backed projection to the engine
`g_8` axis, public likelihood or covariance, and framework-exclusion math.

The next useful artifact is an adapter specification that turns the
partial-wave/detector theory bridges into a concrete projected-measurement
contract, or a public dataset that already supplies that projection.
