# v2.235 - The black-hole tidal Love number vanishes: the 'is it really a black hole?' test

## Question

A fresh, self-contained observable distinct from ringdown: the static tidal RESPONSE rather than the
dynamical QNM. A body in an external tidal field develops an induced multipole; the ratio
(induced response)/(applied tidal field) is the tidal Love number `k_l`. For a general-relativistic
BLACK HOLE this is famously EXACTLY ZERO. Can the repo's static-perturbation machinery verify it,
and why is it the sharp test it is?

## Result

The static (`omega=0`) even-parity `l`-perturbation of Schwarzschild maps to the associated Legendre
equation in `x = r/M - 1` (Hinderer 2008):

```text
(1 - x^2) y'' - 2x y' + [ l(l+1) - 4/(1 - x^2) ] y = 0     (order m = 2)
```

with large-`x` behaviour `x^l` (applied tidal field, "growing") and `x^{-l-1}` (induced response,
"decaying"). The HORIZON-REGULAR solution is the associated Legendre function of the first kind
`P_l^2(x)` -- a PURE POLYNOMIAL of degree `l`:

```text
  l    P_l^2(x)          ODE residual    integrated tail fraction    k_l
  2    3(x^2 - 1)         0.0e+00          3.1e-10                    0
  3    15 x (x^2 - 1)     0.0e+00          4.9e-10                    0
```

Verified two ways: the polynomial solves the perturbation ODE to machine precision (residual
`0`), and direct integration of the ODE from the horizon-regular boundary condition stays a pure
growing polynomial (decaying-tail fraction `< 1e-9`). With no `x^{-l-1}` tail the induced multipole
is zero, so **`k_l = 0` exactly**. (The other solution `Q_l^2` carries the response tail but
diverges at the horizon, so regularity excludes it.)

## What this establishes

A clean, self-contained verification of one of the sharpest predictions in black-hole physics -- the
vanishing tidal Love number -- using the repo's static-perturbation machinery, and the precise
reason (the horizon-regular static perturbation is a tail-free Legendre polynomial). It is the
complement to the ringdown tests: a measured nonzero `k_l` would FALSIFY the black-hole hypothesis
and signal an exotic compact object or new physics, and it is probed by LIGO/Virgo through the
inspiral waveform phase (not the post-merger ringdown). Combined with the ringdown/no-hair/shadow
work, it rounds out the engine's coverage of the strong-field black-hole tests.

## Honest scope

Static (conservative), electric-type (even-parity), `l=2` and `l=3`, 4D Schwarzschild
(non-rotating): in this case `k_l = 0` EXACTLY (verified). Known subtleties beyond this scope: the
magnetic (odd-parity) Love numbers also vanish for Schwarzschild but the analytic continuation in
`l` has a logarithmic-running subtlety; KERR has nonzero DYNAMICAL (frequency-dependent) and
dissipative tidal responses; and higher-curvature / exotic objects give nonzero `k_l` (the signal).
This is the GR baseline against which those are measured, not a new bound. Parity-odd `g_R4_c3`
stays dark (v2.209).
