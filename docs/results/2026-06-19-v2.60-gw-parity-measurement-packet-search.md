## Universal Blockers

Every screened route still fails:

- `missing_external_numeric_gw_bound`
- `missing_engine_axis_projection`
- `missing_public_gw_likelihood`
- `frequency_normalization_not_engine_usable`
- `no_framework_excluding_math`

The SGWB non-observation route is the closest lead because it reports an
order-0.1 constraint scale on generic birefringence parameters. It is still not
claim-ready because the bound is not supplied as a public engine-axis
likelihood for `g_R2_parity` / `g_R3_parity`, and the framework-exclusion math
has not been derived in the ITB normalization.

## Interpretation

The GW parity route is real and source-backed, but it is not yet a quantum
gravity discriminator inside this engine. Existing papers supply useful bounds,
parameterizations, and test designs; none currently satisfies the non-tower
external-measurement guard for an engine-normalized framework exclusion.

The next useful artifact is an adapter from a published GW parity or
birefringence likelihood to `g_R2_parity` / `g_R3_parity`, including frequency
normalization and framework exclusion math.
