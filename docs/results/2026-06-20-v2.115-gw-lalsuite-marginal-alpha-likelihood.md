## Method

The harness reuses the v2.114 alpha grid, then marginalizes each alpha point over
a deterministic nuisance grid with uniform weights:

```text
total_mass_solar = [18.0, 19.0, 20.0]
eta = [0.20, 0.22, 0.24]
tc_shift_seconds = [-0.002, 0.0, 0.002]
phic_rad = [-pi/4, 0.0, pi/4]
nuisance_points = 81 per detector
```

For each detector and alpha point:

```text
log L_marginal(alpha) = logmeanexp_nuisance(log L(alpha, nuisance))
```

This removes the v2.114 blocker:

```text
event_mass_eta_tc_phic_fixed_not_marginalized
```

signal: the coarse nuisance average washes out the fixed-template preference
seen in v2.114, so this cannot be promoted without a real posterior sampler and
calibrated likelihood scale.

## Interpretation

The fixed-event-parameter alpha grid is upgraded into a coarse nuisance-marginal
likelihood over total mass, `eta`, coalescence time, and phase. It is still not a
claim-ready posterior because the nuisance grid is not a sampler, calibration and
systematics are absent, and no v2.102 source-native packet has been exported.
