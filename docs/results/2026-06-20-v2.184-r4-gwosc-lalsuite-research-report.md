# v2.184 - R4/GWOSC/LALSuite research report refresh

## Executive Summary

The June 20 research loop moved the compactification-agnostic R4 route from a
paper-and-manifest frontier into a reproducible, live-data software path:

1. The symbolic R4 scale route has an executable numeric-policy contract.
2. The parallel Weyl/G8 frontier has an executable dual-likelihood contract.
3. Public/source acquisition selected the Bresciani-axis plus GWOSC path.
4. The Bresciani spin-2 R4 axis dictionary is machine-readable.
5. GW170608 public H1/L1 strain files are loaded from GWOSC HDF5 bytes.
6. Source-backed R4 PN channel kernels replace the earlier ansatz response.
7. Vulcan can run LALSuite 7.7.1 and generate an IMRPhenomD reference waveform.
8. H1/L1 detector-channel response has a LALSuite-calibrated RMS target.
9. Follow-up v2.185 regenerated the real GWOSC projection with that calibrated
   H1/L1 response instead of the deterministic detector proxy.
10. Follow-up v2.186 exported an 81-point nuisance-grid covariance contribution
    over event mass, symmetric mass ratio, coalescence time, and phase.
11. Follow-up v2.187 built a coarse network likelihood/posterior over the R4
    axes from real GWOSC strain, LALSuite IMRPhenomD baselines, calibrated H1/L1
    response, and the established nuisance grid.
12. Follow-up v2.188 identified the ParSpec higher-curvature ringdown source as
    a concrete quartic-EFT bridge, importing the published `ell_qEFT <= 51.3 km`
    bound while keeping claim gates closed.

This is progress toward a gravitational-wave discriminator for R4-sensitive
quantum-gravity corrections. It is not a framework exclusion or a discovery
claim. The route still lacks a source-backed map from ParSpec `ell_qEFT` to the
engine R4 axes, public posterior samples or likelihood grids, claim-grade
sampling, calibration/systematics closure, and adversarial review.

## Claim Boundary

The R4 route is now an executable live-data discriminator path, not a solved
quantum-gravity result.

The correct claim is:

```text
The engine can load public GWOSC strain, project a source-backed R4 channel
basis through a documented H1/L1 response path, and export a nonclaiming R4
shape-likelihood seed.
```

The incorrect claim would be:

```text
The engine has excluded or confirmed a quantum-gravity framework from GW data.
```
