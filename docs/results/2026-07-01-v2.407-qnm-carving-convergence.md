# v2.407 - SWING: the swampland-complete carving converges -- the feasible region is near-saturated, so the ~1e-5 predictive volume is a converged answer

## Question

The headline is that intersecting all consistency conditions carves a tiny (~1e-5) region (v2.373). Is that
region **saturated** (the carving converged, a hypothetical extra condition would change it little) or still
**actively shrinking** when the last constraint is added (so ~1e-5 is an overestimate)?

## Result (converged)

Precomputing the per-point per-constraint satisfaction matrix on a local box (constructed +/- 0.15) and
averaging the cumulative-feasible-fraction curve over 300 random constraint orders (removing stack-order bias):

```text
  local-box feasible fraction:  1.0 -> 0.0043 after all 42 constraints
  order-averaged marginal drop:  first-third 0.0555  vs  last-third 0.0030   (taper ~18x)
```

All 5/5 checks pass. The marginal shrinkage per added constraint tapers by ~an order of magnitude.

## What this establishes

The intersection is **near-saturated**: the strong amplitude/swampland conditions carve the region early, and
the remaining conditions largely re-cut already-excluded volume rather than opening new cuts. So the ~1e-5
predictive region is a **converged property** of the swampland-complete intersection, not an artifact of an
incomplete constraint list -- adding more conditions of the *same kind* (further positivity bounds, further
swampland conjectures in the current basis) would move it little. This complements v2.406 (a single global
island) and v2.405 (prefactor-robust): the carving produces **one region, of a converged size, independent of
the toy prefactors** -- three independent senses in which the consistency-driven candidate is a stable output
of the method, not a fragile coincidence. The honest limit stays sharp: convergence is with respect to the
*current kind* of constraint; a genuinely new physical condition (a real ringdown rank-3 map, a resolved
matter-operator basis) could still cut further -- exactly the frontier the basis-refinement program (v2.397)
targets.

## Honest scope

Convergence is measured on a LOCAL box, so it is the local saturation of the carving; the global ~1e-5 is over
the full a-priori box (v2.373), and the local result supports -- but does not re-measure -- global saturation.
The taper is ORDER-AVERAGED over random constraint orders (not a stack-order artifact), but "the last third add
little" is an averaged statement -- specific strong constraints carve a lot wherever they appear. "Converged"
means the marginal carving per constraint of the *current kind* tapers; it does NOT mean the region cannot
shrink further -- a genuinely new physical constraint could carve substantially, and the basis-refinement
frontier is where such cuts would come from. So the claim is "converged with respect to the current constraint
set" -- diminishing returns of the same kind of condition, not a proof the true region equals ~1e-5. The
satisfaction matrix is exact (real check() per point); box sample and order count are finite (percent-level
noise). Robust content: on a local box the feasible fraction saturates and the marginal shrinkage per
constraint tapers ~an order of magnitude (order-averaged), so the swampland-complete carving is near-saturated
and the ~1e-5 region is a converged output for the current constraint kind.
