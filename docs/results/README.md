## How to read a v1.x report

Each `v1.x-*-report.md` is generated by `run_full_battery()` and contains:

- **Constraints in scope** — what's encoded
- **Per-framework status** — feasibility + fragility + nearest binding constraint
- **Pairwise framework distance (fingerprint)** — observational distinguishability
- **2D sweep summary** — allowed-region size + phase components
- **Constraint importance ranking** — which constraints carry the load
- **Cross-class duality (A vs B)** — IoU and per-class cell counts
- **Boundedness** — is the allowed region closed
- **Adversarial bootstrap** — analytic-center / vertex of allowed region
