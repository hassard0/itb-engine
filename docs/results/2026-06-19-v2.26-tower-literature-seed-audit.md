# v2.26 - Tower literature seed audit: qualitative SDC sources are not adapters

**Date:** 2026-06-19
**Compute:** local run plus fresh Vulcan clone `~/codex-runs/itb-engine-main-v226a`
**Input:** v2.24 `TowerSpectrum` contract, v2.25 adapter thresholds
**Artifact:** `experiments/results/v2.26/tower_literature_seed_audit.json`

## Question

v2.25 defined the numerical thresholds a future framework tower adapter must clear.
v2.26 asks:

> Do primary-source tower results already provide an actionable adapter for any registered
> framework?

The answer is no. The strongest seed is the string/SDC literature, but it gives a
qualitative tower relation and species-scale bound, not a normalized `phi_tower_mean`
and uncertainty for the current `string_tree_eft` encoder.

## Sources Audited

Primary sources used:

- Ooguri and Vafa, "On the Geometry of the String Landscape and the Swampland":
  https://arxiv.org/abs/hep-th/0605264
- van de Heisteeg, Vafa, and Wiesner, "Bounds on Species Scale and the Distance
  Conjecture": https://arxiv.org/abs/2303.13580

These support looking for an exponential tower and a species-scale relation, but do not
populate the v2.24 adapter fields.

## Interpretation

This closes an easy failure mode. It would be tempting to treat the Distance Conjecture
as a direct `string_tree_eft` tower adapter. v2.26 blocks that move: the source gives a
tower motivation and asymptotic relation, not a normalized coordinate for the registered
finite-coefficient framework instance.

The defensible claim is:

> The string/SDC literature justifies a tower-adapter search, but it does not yet supply
> an actionable `TowerSpectrum` for this engine. There are still no framework-level
> tower exclusions.

## Code changes

- `experiments/tower_literature_seed_audit.py` records primary-source tower seeds and
  checks them against the v2.24 adapter contract.
- `tests/test_tower_literature_seed_audit.py` locks the guardrail that qualitative SDC
  sources are not actionable spectra.
- `experiments/results/v2.26/tower_literature_seed_audit.json` stores the verified
  artifact.

## Bottom line

The next real step is narrower than "use the Distance Conjecture." It is to derive or
fit a normalized `phi_tower_mean`, `phi_tower_sigma`, and normalization map for a
specific registered framework.
