```text

g_R4_c2 = 0.495614794648

```

It builds a 5x5x5 coefficient grid around those values:

```text
offsets = -0.04, -0.02, 0.0, 0.02, 0.04
grid_points = 125
```

For each H1/L1 detector and each of the 81 v2.115 nuisance points, it builds
linearized R4 waveform templates from:

```text

```

## Claim Boundary

This removes the v2.186 scaffold blocker:

```text
uniform_grid_covariance_scaffold_not_waveform_likelihood
```

It does not produce a claim-grade R4 reanalysis. The remaining blockers are:

```text
full_r4_modified_imr_merger_ringdown_completion_missing
r4_likelihood_uses_linearized_pn_templates_not_source_owned_waveform
nuisance_grid_is_coarse_not_posterior_sampler
waveform_calibration_prior_and_eft_systematics_not_closed
external_adversarial_review_missing
```

The correct next artifact is a source-owned full R4 IMR likelihood or posterior
sampler that includes merger-ringdown, calibration priors, EFT systematics, and
external adversarial review.

Follow-up v2.188 splits that blocker by identifying the ParSpec higher-curvature
ringdown source bridge and importing the quartic-EFT length-scale bound. It does
not close the claim boundary because the source still needs an engine-axis map,
public posterior or likelihood samples, event-set alignment, and systematics
export.
