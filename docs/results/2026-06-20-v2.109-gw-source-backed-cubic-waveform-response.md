## Interpretation

The alpha response basis is no longer an arbitrary proxy. It is built from the
source paper's cubic-EFT inspiral phase and relative-amplitude corrections for
`alpha_bar_1` and `alpha_bar_2`.

This is still not a Liu-Yunes-style alpha likelihood. The response has not yet
been mapped through detector PSD/calibration, event mass and `eta` uncertainty,
merger-ringdown treatment, or the source-native posterior packet gate.
