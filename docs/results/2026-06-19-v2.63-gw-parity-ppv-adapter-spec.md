## Required Formula Work

The Ng adapter needs:

- native exponent convention for left/right circular GW amplitudes;
- Jenks PPV amplitude-branch axis and sign convention;
- distance normalization and cosmology convention;
- frequency reference conversion at 100 Hz;
- posterior sample parser for `kappa`.

The Callister adapter needs:

- `kappa_D` distance term;
- `kappa_z` redshift term;
- joint posterior-grid loader;
- normalization between the SGWB exponent and PPV amplitude branch;
- cosmology convention for distance/redshift conversion.

## Validation Tests Required Next

- zero native parity parameter maps to zero PPV amplitude;
- helicity sign is preserved;
- 100 Hz reference-frequency roundtrip is exact;
- posterior mass integrates to one;
- Callister distance and redshift terms remain separable.

## Interpretation

The shared PPV amplitude branch is the right intermediate target for Ng and
Callister, but v2.63 does not implement a numeric adapter. It records the exact
formula, sign, normalization, and parser obligations that must be satisfied
before a non-promoting PPV loader can be added.

No `g_R2_parity` / `g_R3_parity` projection is allowed by this artifact.
