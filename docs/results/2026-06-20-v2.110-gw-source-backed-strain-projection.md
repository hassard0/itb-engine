## Method

The harness reuses the v2.108 conditioned 4-second event-centered H1/L1 strain
segments, then:

- computes the real FFT of the conditioned strain
- selects the source-backed inspiral frequency window using `v_f`
- converts the strain spectrum into a centered, unit-norm log-magnitude feature
- normalizes the v2.109 source-backed phase and amplitude response kernels
- computes source-weighted spectral-shape projections for each detector

Reference settings:

```text
total_mass_solar = 19.0
eta = 0.22
minimum_frequency_hz = 20.0
maximum_v_f = 0.32
```

This removes the v2.109 blocker:


## Interpretation

The source-backed alpha response now touches the verified public strain in
frequency space. This is still not an alpha likelihood or matched-filter
estimate. It uses a reference mass and eta, a spectral-shape feature, and no
detector PSD/calibration model.

The next artifact must turn this diagnostic into a PSD-whitened complex
frequency-domain residual with a GR waveform phase reference and posterior
sampling over the event parameters.
