## Release Contract

The parser targets the fixed-rate HDF keys documented by the Callister public
code under the top-level `/result` group:

```text
kappa_dcs_1D
probability_kappa_dc_1D
kappa_zs_1D
probability_kappa_z_1D
kappa_dcs_2D
kappa_zs_2D
probabilities
```

For the joint grid, the parser enforces the documented order:

```text
probabilities[i,j] -> posterior(kappa_dcs_2D[i], kappa_zs_2D[j])
```

Expected fixed-rate release filenames:

```text
fixed_rate_uniform.hdf
fixed_rate_SFR.hdf
fixed_rate_delayedSFR.hdf
fixed_rate_delayedSFR_HLO1.hdf
fixed_rate_delayedSFR_HLO2.hdf
fixed_rate_delayedSFR_HLO3.hdf
fixed_rate_delayedSFR_HVO3.hdf
fixed_rate_delayedSFR_LVO3.hdf
```

## Validation Fixture

The committed artifact does not bundle Zenodo HDF bytes. Instead it runs a
synthetic release-shaped fixture under `/result` through the exact parser
contract:

| field | value |
|---|---:|
| `kappa_D` 1D normalized mass | `0.9999999999999998` |
| `kappa_z` 1D normalized mass | `0.9999999999999998` |
| joint normalized mass | `1.0` |
| joint shape | `[17, 19]` |

The parser also has guards for:

- missing release keys
- one-dimensional grid shape mismatches
- joint grid order/shape mismatches
- non-finite coordinates or densities
- negative posterior density
- non-positive posterior mass

## Remaining Blockers

- `real_zenodo_hdf_file_not_bundled`
- `h5py_optional_dependency_not_installed_in_current_venv`
- `helicity_convention_not_harmonized_across_sources`
- `ppv_beta1_normalization_not_finalized`
- `engine_projection_out_of_scope`

The parser narrows the ingestion blocker from "unknown release parser" to a
specific HDF schema and normalization contract. It still does not download or
commit the public release data, and it does not promote `kappa_D` or `kappa_z`
to `g_R2_parity`, `g_R3_parity`, or a final PPV `beta_1`.

## Interpretation

This is a concrete forward step: a real Callister fixed-rate HDF file can now be
wired into `load_callister_fixed_rate_hdf` once `h5py` is available in the
runtime. The result remains source-native posterior material only. No
quantum-gravity solution claim is available from this artifact.
