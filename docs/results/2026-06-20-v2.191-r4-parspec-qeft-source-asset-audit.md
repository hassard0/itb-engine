
The source package has useful figure assets, but the figures are not enough for
claim-grade engine likelihood attachment. A next artifact needs either a public
ParSpec/qEFT posterior sample set or a log-likelihood/covariance object, plus a
source-backed map into `g_R4_c1`, `g_R4_c2`, and `g_R4_c3`.

## Claim Boundary

The correct claim is:

```text
The repo has audited the public ParSpec/qEFT source package and preserved the
source-backed qEFT ParSpec power and QNM deformation coefficients.
```

The incorrect claim would be:

```text
The repo has attached the ParSpec/qEFT posterior to the engine R4 axes or
derived a claim-grade qEFT-to-Bresciani R4 map.
```

No framework exclusions are claimable from this artifact.
