# v2.296 - The cutoff bracket: a derived lower bound on the relative curvature coupling

## Question

FIFTH SLICE of the new-theory arc, completing the cross-sector characterization. The v2.295 map left a
third, unexplored handle on the shared-spectrum hypothesis: `w <= W`. What does bounding the relative
curvature/matter weight by `W` give?

## Result (the third handle: a derived relative-coupling lower bound)

The relative weight `w(M^2) = (curvature coupling)/(matter coupling)` for a state of mass `M`; `W = sup w`
is the largest relative curvature coupling anywhere in the spectrum. If `w <= W`, the bracket measure
`(W - w) dmu` is positive, so `{W m_k - c_k}` is a valid moment sequence and its Hankel is PSD:

```text
  (W m_0 - c_0)(W m_2 - c_2) >= (W m_1 - c_1)^2
  <=>  C W^2 - B W + A >= 0    (A, B, C as in v2.294)
  =>   W >= W_+ = ( B + sqrt(B^2 - 4 A C) ) / (2 C)
```

Computed per framework (`g_R4` at the v2.234 forced minimum, so the curvature Hankel saturates `A = 0`
and `W_+ = B/C`):

```text
  framework          A      B        C        W_+      max r_k   sharpens?
  string_tree_eft    0.000  0.0163   0.0400   0.406    0.400     yes
  asymptotic_safety  0.000  0.0117   0.0300   0.389    0.375     yes
  cdt                0.000  0.0133   0.0325   0.408    0.400     yes
  lqg_induced        0.000  0.0300   0.0375   0.800    0.750     yes
```

Each `W_+` slightly exceeds the trivial bound `max_k r_k` (Hankel positivity sharpens `W >= max-ratio`)
and is a genuine bracket (the bracket Hankel is PSD exactly at `W_+`). **lqg has the largest `W_+`
(0.80)** -- its curvature couples most strongly relative to its matter sector, the recurring anomaly. The
physical reading: given the observed moment ratios, SOME state in the shared tower must couple to
curvature at least `W_+` times as strongly as to matter -- the curvature sector cannot be uniformly
weakly coupled. All 5/5 checks pass.

## Honest scope

The bracket derivation (`(W-w)mu >= 0 => {W m_k - c_k}` Hankel PSD `=> W >= W_+`) is exact linear algebra,
verified. The ASSUMPTION `w <= W` with finite `W` is the bounded-weight refinement (the curvature coupling
is not unboundedly larger than the matter coupling) -- physical, not a theorem, same status as the v2.295
monotone-`w` assumption. `W` is the maximum RELATIVE curvature/matter spectral coupling, NOT directly the
EFT cutoff scale (relating them needs the operator normalization the toy basis sets to O(1)); so
`W_+ ~ 0.4-0.8` is a dimensionless relative-coupling floor, not a scale in GeV. `g_R4` at the forced
minimum makes `A = 0` (saturated curvature tower), so `W_+ = B/C` here; a larger `g_R4` gives a different
`W_+`. Toy basis, O(1) prefactors. A new-engine-theory result completing the cross-sector arc.
