## Source

Primary source:

```text
Silva, Ghosh, Buonanno, "Black-hole ringdown as a probe of higher-curvature gravity theories"
arXiv:2205.05132
Phys. Rev. D 107, 044030 (2023)
```

Source URLs:

```text
https://arxiv.org/abs/2205.05132
https://doi.org/10.1103/PhysRevD.107.044030
```

The source uses an effective-one-body IMR waveform augmented with a parametrized
ringdown expansion and theory-by-theory quasinormal-mode inputs. It covers
quartic-order EFT corrections and reports:

```text
ell_qEFT <= 51.3 km at 90% credible level
events = GW150914, GW200129
```

## Bridge

posterior frontier:

and four remaining subpieces:

```text

event_set_mismatch_gw170608_vs_gw150914_gw200129
```

The bridge is not claim evidence. It imports a primary source and a published
quartic-EFT bound, but it does not provide an engine-normalized likelihood over
`g_R4_c1`, `g_R4_c2`, and `g_R4_c3`.

## Next Step

The correct next artifact is one of:

```text
1. a public ParSpec/qEFT posterior sample or likelihood grid for ell_qEFT
2. a source-backed map from ell_qEFT to engine R4 axes
3. a re-run or compatible likelihood export on the same event set as the engine
```

Follow-up [v2.190](2026-06-20-v2.190-r4-parspec-engine-axis-map-contract.md)
turns item 2 into an executable packet contract. It does not fill the real map;
it names the source-axis power, Bresciani-basis orientation, normalization,
covariance-pushforward, event-set, likelihood, and systematics fields that a
future source packet must provide.
Follow-up [v2.191](2026-06-20-v2.191-r4-parspec-qeft-source-asset-audit.md)
then fills the source-axis power subpiece from the public arXiv source package
with `p_qEFT = 6` and preserves the qEFT QNM coefficients and event bounds. It
does not provide public likelihood samples or the engine-normalized Bresciani
R4-axis map.

Until then, the route is a source bridge and not a framework exclusion.
