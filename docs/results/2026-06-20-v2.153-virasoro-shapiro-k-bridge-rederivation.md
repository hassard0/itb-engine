## Rederivation

Restoring `alpha_prime` gives:

```text
sbar*tbar*ubar = alpha_prime^3*s*t*u/64
```

The Russo pole term is therefore:

```text
A4_string_pole = kappa^2*K_Russo*64/(alpha_prime^3*s*t*u)
```

The Kallosh tree comparator is:

```text
M_tree_helicity = shape/(kappa^2*s*t*u)
```

Pole matching gives:

```text
kappa^2*K_Russo*64/alpha_prime^3 = shape/kappa^2
K_Russo / shape = alpha_prime^3/(64*kappa^4)
```

Setting `alpha_prime = 1` recovers the v2.146 raw control bridge:

```text
K_Russo / shape = 1/(64*kappa^4)
```

The R4 contact after pole matching is:

```text
2*zeta(3)*alpha_prime^3*shape/(64*kappa^2)
```
