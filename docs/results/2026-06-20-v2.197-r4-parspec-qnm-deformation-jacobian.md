## What Ran

The artifact reads the v2.196 published-bound surrogate and the qEFT QNM
deformation coefficients preserved by v2.191. It computes a source-space
pushforward from `ell_qEFT_km` into ParSpec qNM deformation coordinates:

```text
normalized_gamma = (ell_qEFT_km / upper_bound_km_90)^6
d normalized_gamma / d ell = 6 ell_qEFT_km^5 / upper_bound_km_90^6
```

This normalization is deliberately local to each published 90% bound. The
absolute source ParSpec `gamma` relation still requires remnant mass and
redshift:

```text
gamma = (ell_th c^2 (1 + z) / (G M_f))^p
p_qEFT = 6
```

So v2.197 is a source-space deformation Jacobian, not a completed engine-axis
map.

## QNM Coefficients

The source qEFT coefficient vector is:

```text
delta_omega_qeft_0 = -0.2114
delta_tau_qeft_0   = -0.607
delta_omega_qeft_1 = -1.5263
delta_tau_qeft_1   = 171.35
```

For each source row, v2.197 exports:

```text
qnm_deformation = coefficient_vector * normalized_gamma
dqnm_deformation_d_ell_km = coefficient_vector * d_normalized_gamma_d_ell_km
```

At the published-bound point, `normalized_gamma = 1`, so the qNM deformation
matches the source coefficient vector exactly.

## Claim Boundary

The correct claim is:

```text

QNM deformation coordinates.
```

The incorrect claim would be:

```text

framework exclusion.
```

No framework exclusions are claimable from this artifact.
