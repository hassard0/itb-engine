# v2.294 - The rigorous cross-sector bound (and an honest correction to v2.293)

## Question

THIRD SLICE of the new-theory arc (swing for breakthroughs; honest negatives reported). v2.293 proposed
that matter and curvature couplings are moments of one shared spectral density and tested it with a

calibration-free bound -- and does the v2.293 band survive that scrutiny?

## Result (a derived bound, and an honest demotion of v2.293's heuristic)

**Derivation (no calibration).** If the matter moments `m_k` and curvature moments `c_k` come from one
measure `mu` with positive relative weight `w >= 0`, then for every `t >= 0` the TILTED measure
`(1 + t w) dmu` is positive, so `{m_k + t c_k}` is a valid Stieltjes moment sequence and its Hankel
matrix is PSD for all `t >= 0`. At the 2x2 (three-moment) level:

```text
  det[[m_0+t c_0, m_1+t c_1],[m_1+t c_1, m_2+t c_2]] = A t^2 + B t + C >= 0   for all t >= 0
     A = g_R2 g_R4 - g_R3^2   (curvature-tower margin)
     C = g_4 g_8 - g_6^2      (matter-tower margin)
     B = g_4 g_R4 + g_R2 g_8 - 2 g_6 g_R3   (the CROSS term)
  => rigorous bound:  B >= -2 sqrt(A C)    (no calibrated threshold)
```

**Honest finding: the bound is automatically satisfied.** By AM-GM and the two towers,
`g_4 g_R4 + g_R2 g_8 >= 2 sqrt(g_4 g_8 . g_R2 g_R4) >= 2 sqrt(g_6^2 . g_R3^2) = 2 g_6 g_R3`, so `B >= 0`
ALWAYS (verified for every framework and on random tower-satisfying points):

```text
  framework          A(curv)   C(matter)   B(cross)   B>=0   tilted-Hankel ok
  string_tree_eft    0.0000    0.0400      0.0163     yes    yes
  asymptotic_safety  0.0000    0.0300      0.0117     yes    yes
  lqg_induced        0.0000    0.0375      0.0300     yes    yes
  cdt                0.0000    0.0325      0.0133     yes    yes

  v2.293 DECOUPLED (g_R4 = 2.0):  B = 0.96 >= 0,  tilted-Hankel ok  -> PASSES the rigorous bound
```

The 2x2 tilted-Hankel therefore adds **NO** new information beyond the matter and curvature towers at
three moments per sector. And the v2.293 decoupled counterexample (`g_R4 = 2.0`), which the CALIBRATED
ratio-band rejected, has `B = 0.96 >= 0` and **passes** this rigorous bound -- so the v2.293 band was a
heuristic STRONGER than the shared-measure hypothesis actually justifies. All 5/5 checks pass.

## What this establishes

This is the swing-and-honestly-check discipline in action. v2.293 proposed a cross-sector principle that
appeared to have teeth (rejecting a point both towers accept); v2.294 derives the *rigorous* consequence

is implied by the two towers (via AM-GM) and adds nothing. The honest correction stands, AND it points

further operator extension, not the present moment depth.
