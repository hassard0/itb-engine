## Parser Summary

All eight fixed-rate files passed the guarded parser:

```text
all_fixed_rate_parsers_ready = true
```

Every fixed-rate HDF file had:

- `kappa_D` 1D grid: 400 points, range `[-0.2, 0.2]`, normalized mass `~1`
- `kappa_z` 1D grid: 400 points, range `[-0.4, 0.4]`, normalized mass `~1`
- joint grid: shape `[400, 399]`, ranges `kappa_D=[-0.5, 0.5]`, `kappa_z=[-1, 1]`, normalized mass `~1`

The artifact records compact peak locations for each file, but not the raw
posterior densities. Raw Zenodo data stays in a local temp/cache directory.

## Remaining Blockers

- `variable_rate_hdf_parser_not_implemented`
- `helicity_convention_not_harmonized_across_sources`
- `ppv_beta1_normalization_not_finalized`
- `engine_projection_out_of_scope`

This closes the fixed-rate real-file ingestion blocker. It does not parse the
separate `birefringence_variable_evolution.hdf` product, and it still does not
turn `kappa_D` or `kappa_z` into `g_R2_parity`, `g_R3_parity`, or a final PPV
`beta_1` engine-normalized likelihood.

## Interpretation

The Callister SGWB branch is now stronger as source-native evidence plumbing:
formula implementation, fixed-rate schema parser, and real-file verification are
all present. The physics discriminator remains blocked on variable-rate coverage,
helicity harmonization, PPV normalization, and a source-backed engine-axis map.

No quantum-gravity solution claim is available from this artifact.
