# v1.87 — The Gödel test: is the engine internally consistent, and what are its minimal inconsistent cores?

**Date:** 2026-06-08
**Compute:** Vulcan (16-core; 1.5M-sample bitmask cache).

---

## A different kind of experiment

The first of a new "meta-experiment" track (auditing the engine itself rather than
the theories). The question: **is the engine's own ~40-constraint axiom set
logically consistent — and where are its irreducible tensions?** This is a Gödel-style
self-audit: not "which theory survives" but "do the principles + the data ever
contradict each other, and if so, *minimally* how?"

## Method — sample once, then reason in bitmasks

Feasibility of a *subset* of constraints is expensive to check naively. The trick:
sample the 8-coefficient box once (1.5M points), and for each point cache its
per-constraint **satisfied-bitmask** as a single integer. Then *any* subset T's
feasibility is the instant bitwise test `((bits & maskT) == maskT).any()` — so the
minimal-unsatisfiable-subset (MUS) search needs no re-sampling. "Infeasible" is
operational at the sampling resolution: 0 of 1.5M box-samples ⇒ the joint allowed
region is < ~7×10⁻⁷ of the box (a genuine tension).

## Result 1 — the principles are internally consistent

The **theoretical-only stack is feasible**: 398 / 1.5M survivors (0.027%). So the
**~37 theoretical axioms — amplitude positivity, causality, holographic entropy,
swampland, anomaly flow, BH-entropy/WGC — are mutually consistent. There is no
internal (Gödel-style) contradiction among the principles.** Whatever the engine
excludes, it excludes for physics reasons, not because its own rules fight each
other.

## Result 2 — the minimal inconsistent cores are all empirical

The full set (theory + 4 data constraints) *is* infeasible. A randomized
deletion-MUS search found **6 minimal inconsistent cores**. The **smallest, size 3**:

> **{ generalized_anomaly_inflow + sub-mm gravity + cosmic birefringence }**

This is *exactly* the v1.79 dark-energy-scalaron tension — the scalaron cannot be
simultaneously unscreened-sub-mm-safe (g_R2 small) and birefringence-matching
(g_R2_parity ~ 0.1) while anomaly inflow ties the parity coupling to the
matter–curvature product — now **recovered systematically** by the audit rather than
stumbled into. The other 5 cores (size 5–6) are sub-mm-driven: sub-mm + the
Hofman–Maldacena wedge + the distance conjecture + anomaly inflow + one more
positivity bound (forward positivity, or EFThedron, or CEMZ, or the cubic
graviton-matter bound, …) — alternative minimal ways the *unscreened dark-energy
cutoff* clashes with the consistency stack.

**Crucially, every minimal core contains a DATA constraint.** The principles never
contradict each other; inconsistency appears *only* when an experiment is added. And
notably **GW speed and GW dispersion appear in no core** — they create no irreducible
tension (consistent with v1.84/85: the speed test is blind, the dispersion test is
only at the frontier). The engine's "inconsistencies" are precisely the real physics
tensions in *what we believe + what we measure.*

## Result 3 — the pairwise tension heatmap

Among the theoretical axioms, the most anti-correlated margin pairs (over survivors)
are structural *trade-offs*, not contradictions — e.g. `eft_validity_box` (bounds
coefficients from above) vs `scalar_positivity_g4` (from below) are perfectly
anti-correlated within the thin survivor sliver. The heatmap (figure, right panel)
maps which principles pull against each other while still jointly satisfiable — a
portrait of the island's shape from the constraints' point of view.

## Interpretation

This is the engine certifying its own soundness and then localizing its tensions:

1. **Logically sound.** The ~37 principles admit a common solution — no axiom
   contradicts the others.
2. **Empirically tense.** The only minimal inconsistent cores arise from adding data,
   and the *smallest* is the anomaly-inflow / sub-mm / birefringence triangle — the
   sharpest statement the program has: the dark-energy scalaron is over-constrained
   by two experiments + one consistency condition.
3. **Honest resolution unchanged.** Screening (relaxing sub-mm) dissolves the size-3
   core, exactly as v1.79–80 found — now visibly *because* removing the sub-mm node
   breaks every core that contains it.
