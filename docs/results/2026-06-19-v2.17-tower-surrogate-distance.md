## Question

v2.16 showed that the parity-lobe topology is functional-form dependent. The next
question is not "what is the right Distance Conjecture?" It is a narrower acceptance
gate:

> Can an explicit continuous tower/species surrogate remove the known near-zero parity
> discontinuity while preserving the corrected-stack topology and known framework
> verdicts?

The current hard distance prior is a coefficient max/min rule. That is too far from the
Swampland Distance Conjecture's moduli-space and tower-of-states content. v2.17 tests
four continuous tower-load surrogates:

- curvature L1: `|g_R2| + |g_C| + |g_R3|`,
- curvature L2,
- curvature plus parity L2,
- curvature L2 plus parity-vector norm.

All are encoded as:

```text
N_tower(g) = 1 + nu * tower_load(g) <= N_max
```

This is still not a canonical SDC implementation. It is closer to species/tower language
than a coefficient aspect ratio, but it lacks an explicit moduli-space metric and a real
tower spectrum.

Primary sources:

- Dvali and Redi, *Black Hole Bound on the Number of Species and Quantum Gravity at LHC*:

- van de Heisteeg, Vafa, and Wiesner, *Bounds on Species Scale and the Distance Conjecture*:

- van de Heisteeg, Vafa, Wiesner, and Wu, *Moduli-dependent Species Scale*:

## Result

All four candidates pass the basic surrogate gate at `N_max=3.0`:

1. reconnect all four parity lobes through the parity-zero detour,
2. introduce no additional framework exclusions relative to the stack with the old hard
   distance/species sector removed,
3. fail no known framework by the surrogate alone,
4. show no epsilon-to-zero punctured parity gap,
5. tighten monotonically as curvature/tower load increases.

| tower surrogate | first accepting `N_max` | max `N_tower` on v2.13 lobe centroids | punctured near-zero gap | monotone margin |
|---|---:|---:|---:|---:|
| curvature L1 | `2.8` | `2.5479` | no | yes |
| curvature L2 | `2.4` | `1.9850` | no | yes |
| curvature + parity L2 | `2.4` | `1.9929` | no | yes |
| curvature L2 + parity norm | `2.6` | `2.1098` | no | yes |

The default stack baseline still fails the parity-zero detour with:

```json
{"swampland_distance_conjecture": 4}
```

Removing the hard distance/species sector reconnects the lobes. Adding any of the
four continuous tower surrogates at `N_max=3.0` preserves that reconnection.

## Interpretation

v2.17 does **not** solve the Distance Conjecture encoding. It establishes a practical
acceptance gate for candidate replacements:

> A continuous tower/species surrogate can remove the discontinuous parity-zero artifact
> without immediately changing the known framework verdicts.

That makes these surrogates better next candidates than the hard max/min distance prior.
It does not make them independent or physically complete. The v1.96 species-scale result
already found that the current species proxy is redundant in this basis, so the next test
must measure irreplaceability and overlap.

## Remaining work

The next loop should run a Jenga/overlap audit for the tower surrogates:

- island growth when the surrogate is removed,
- overlap of surrogate failures with `complexity_cutoff`,
  `swampland_distance_conjecture`, and `species_scale_bound`,
- whether any candidate creates a genuinely new wall rather than another aggregate
  curvature cap.

The harder physics requirement remains open: a real moduli/tower surrogate needs a
field-space coordinate, a tower-mass law, and a species cutoff tied to that tower.

The current hard distance prior should not be used for topology claims. Continuous
tower/species surrogates pass the first sanity gate and are therefore the right objects
for the next adversarial loop, but the engine still does not have a full physical
Swampland Distance Conjecture implementation.
