# v2.268 - GW polarization content: GR's two modes vs the six of a general theory (and the interferometer rank-5 wall)

## Question

A fresh falsifiable-gravity probe (continuing the v2.266/v2.267 GW thread). A massless spin-2 metric
theory can carry up to six gravitational-wave polarizations (the Eardley-Lee-Will E(2) set), but
general relativity predicts exactly two. How many can a real interferometer network actually separate?

## Result

The six polarization strain tensors (for z-propagation) form a COMPLETE basis for the symmetric 3x3
strain (rank 6, verified), split into tensor / vector / scalar pairs:

```text
  mode          class    traceless  transverse   in GR?
  plus          tensor   yes        yes          YES
  cross         tensor   yes        yes          YES
  breathing     scalar   no         yes          no
  longitudinal  scalar   no         no           no
  vector_x      vector   yes        no           no
  vector_y      vector   yes        no           no
```

GR excites only the two TENSOR modes, which are exactly the transverse-and-traceless ones (verified);
every non-GR mode breaks transverse-tracelessness, so **detecting any non-tensor polarization
falsifies GR's polarization content**. But interferometers face a sharp limit: the Michelson response
tensor `D = 1/2(a(x)a - b(x)b)` is **traceless** (verified), so it sees only the traceless part of each
mode -- and the two SCALAR modes (`breathing = diag(1,1,0)`, `longitudinal = diag(0,0,1)`) have
**proportional (antiparallel) traceless parts** (verified). No interferometer network can ever
separate them. The `(detectors x 6)` response matrix therefore saturates at **rank 5, not 6**
(verified): an interferometer array resolves at most five polarization combinations, the two scalars
collapsing to one. A single detector with the source overhead is even more degenerate -- it responds
*only* to plus. GR's two-mode content needs just two detectors (gr submatrix rank 2). All 8/8
consistency checks pass.

## What this establishes

The polarization content of gravity is a model-independent, falsifiable test, and the analysis pins
down exactly what is measurable: six modes exist in principle, but the traceless Michelson response
makes the two scalar modes fundamentally degenerate for interferometers, capping the separable count
at five (Chatziioannou-Yunes-Cornish). This is why current three-detector events (GW170814) test
tensor-vs-vector-vs-scalar HYPOTHESES -- and favour pure tensor -- rather than measuring all
amplitudes. It extends the v2.266/v2.267 GW thread from the graviton's mass and infrared structure to
its spin/polarization content.

## Honest scope

The six strain tensors, their TT classification, the single-detector degeneracy, the traceless-
response scalar degeneracy, and the rank-5 network result are EXACT for the idealized Michelson
response `D = 1/2(a(x)a - b(x)b)`. The rank result uses a deterministic set of rotated ideal
detectors; a real network's separability also depends on sky position, noise and source amplitudes
(the actual LIGO/Virgo polarization tests are Bayesian model comparisons, not a literal rank count).
The scalar-mode degeneracy is specific to INTERFEROMETERS -- pulsar-timing arrays, sensitive to the
trace differently, can in principle break it. The E(2) class of a specific alternative theory
(Brans-Dicke etc.) is not computed here; this is the model-independent polarization-content framework.
A falsifiable-gravity / GW-phenomenology result, not an engine constraint refit.
