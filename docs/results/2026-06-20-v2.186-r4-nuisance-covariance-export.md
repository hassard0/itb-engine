## Method

The artifact starts from the v2.185 calibrated projection:

```text
g_R4_c1 = 0.495629103212
g_R4_c2 = 0.495614794648
g_R4_c3 = -0.003513023764
```

It applies the existing v2.115 GW nuisance-grid convention:

```text
total_mass_solar = 18.0, 19.0, 20.0
eta = 0.20, 0.22, 0.24
tc_shift_seconds = -0.002, 0.0, 0.002
phic_rad = -pi/4, 0.0, pi/4
```

This yields 81 uniformly weighted nuisance points. The export records a
deterministic sensitivity map from those nuisance offsets into the R4 projection
axes, then adds the induced nuisance covariance to the v2.185 covariance seed.

Exported covariance:

```text

```

```text

```

It does not produce a claim-grade posterior sampler. The remaining blockers are:

```text
full_imr_r4_merger_ringdown_completion_missing
waveform_calibration_prior_and_eft_systematics_not_closed
external_adversarial_review_missing
nuisance_grid_is_coarse_not_posterior_sampler

```

The correct next artifact is a real R4 waveform likelihood over the same
nuisance axes, replacing this uniform-grid covariance scaffold with a
posterior or source-owned likelihood export.

Follow-up v2.187 completes the first part of that next artifact by replacing
the covariance-only scaffold with a coarse network waveform-likelihood posterior
over the R4 axes. It does not close the claim boundary; the next open step is a
source-owned full R4 IMR likelihood/posterior sampler.
