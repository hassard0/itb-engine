## Blocker Movement

The v2.191 blocker:

```text
event_set_mismatch_gw170608_vs_gw150914_gw200129
```

is now split into:

```text
resolved:
  gwosc_source_event_versions_and_hdf5_urls_identified

remaining:
  rerun_engine_likelihood_on_gw150914_and_gw200129
  gw200129_v1_detector_topology_policy
  public_parspec_qeft_likelihood_or_posterior_samples
```

The event discovery and public strain URL subpiece is resolved. The engine's
actual likelihood is still not aligned, because the current live-data R4 run is
still the GW170608 path.

## Remaining Blockers

The v2.192 alignment blockers are:

```text
current_engine_event_set_not_parspec_source_events
gw200129_v1_detector_topology_policy_missing
public_parspec_qeft_likelihood_or_posterior_samples_missing
operator_basis_map_missing
engine_axis_orientation_missing
axis_normalization_missing
```

`GW200129_065458-v1` has H1/L1/V1 public strain. The current engine's live-data
path is H1/L1-centered. A claim-grade same-event rerun must either include V1
or explicitly justify an H1/L1-only projection against the ParSpec source
analysis.

## Claim Boundary

The correct claim is:

```text
The repo now has a tested public-GWOSC manifest for the two ParSpec/qEFT source
events, including exact event versions and 4 kHz HDF5 strain URLs.
```

The incorrect claim would be:

```text
The engine has attached the ParSpec/qEFT likelihood to a same-event R4 run.
```

No framework exclusions are claimable from this artifact.
