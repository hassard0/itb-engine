## What this cycle does

v1.39–41 built the decisive-experiment program as standalone analysis scripts.
This cycle makes it **permanent infrastructure**: the three observables are now
first-class `Observable` subclasses in `src/itb/gravitational_observables.py`
(predict + analytic Jacobian), so the engine's Fisher-metric and
first-disagreement machinery can rank them natively against the amplitude
observables — no bespoke scripts needed.

| observable | physics | depends on | predict |
|---|---|---|---|
| `YukawaForceDeviation` | short-range gravity (R² Stelle scalar) | g_R2 | δ(r) = −(1/3) e^(−r/λ_Y), λ_Y = ℏc/m₀, m₀ = E_Λ/√(6 g_R2) |
| `GravitationalBirefringence` | GW parity rotation | g_R2_parity, g_R3_parity | a + (ω/ω₀) b |
| `GIEPhaseCorrection` | entangling-phase shift | g_R2 | −(1/3) e^(−r/λ_Y) at the superposition scale |

## Verification

Tests (`tests/test_gravitational_observables.py`, 6 cases, all green; full suite
**374 passed**) pin the physics against the earlier analysis:

- The Yukawa deviation reproduces the v1.41 spec-sheet numbers (string −11.9 %,
  parity-violating branch −16.0 % at r = 93 µm). *A √6 factor in m₀ was caught
  and fixed by this test* — the standalone spec-sheet script had it right, the
  first draft of the observable did not; the regression test now guards it.
- Larger g_R2 → lighter scalar → deviation persists to longer range (bigger |δ|).
- Analytic Jacobian matches finite differences (rtol 1e-3).
- Birefringence vanishes for parity-conserving theories, is nonzero otherwise,
  and its Jacobian is ω/ω₀ in the cubic-parity direction.
- The GIE correction is negative (the scalar *reduces* the entangling phase —
  Dr. M.'s sign).

## Why it matters

The decisive-experiment program is no longer a set of one-off scripts — it is
part of the engine's observable basis. Any future Fisher/discrimination analysis
(e.g. ranking experiments, computing required precision for a new candidate
theory) now automatically includes short-range gravity, birefringence, and GIE
alongside the matter/graviton amplitudes. The path from a constrained theory to
its experimental signature is wired in.
