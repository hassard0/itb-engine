## Method

The harness installs the optional `gw` dependency group on Vulcan, then:

- generates a LALSuite `IMRPhenomD` frequency-domain `h_plus` baseline
- keeps the v2.112 off-source PSD whitening path
- multiplies the source-backed cubic response by the IMR baseline
- projects the normalized PSD-whitened event data onto those source-response templates

This removes the v2.112 blocker:

```text
leading_order_gr_reference_not_full_imr
```

## Interpretation

The projection layer now uses a real LALSuite IMRPhenomD waveform baseline
instead of a hand-built leading-order inspiral reference. This is still not a
claim-ready likelihood because event parameters and `alpha_bar` are not sampled,
and no posterior/systematics packet has been exported.
