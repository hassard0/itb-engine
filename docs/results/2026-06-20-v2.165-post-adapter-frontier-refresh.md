## Claim Boundary

This iteration improves route ordering and records new infrastructure, but it
does not make a framework exclusion. R4 needs a public covariance packet, g_8
needs an external measurement packet, native towers need one complete
source-owned registered-framework adapter, Weyl/g_8 needs dual external
likelihoods, parity needs a source-backed operator bridge, and R4 scale needs a
numeric compactification/frame policy.

Best next artifact:

```text
A real public packet satisfying the v2.160 manifest with a covariance over g_R4_c1, g_R4_c2, and g_R4_c3. The adapter will score it against the registered string-tree R4 shape but will still require adversarial review before any framework claim.
```
