# v2.54 - g8 high-moment measurement specification: the route is defined, not satisfied

## Question

v2.53 made `matter_high_moment_g_8` the highest-priority unsolved route. The
problem was not island geometry; it was that the route was still an internal
design probe. This audit asks what a real external spin-4, detector, or
high-moment measurement packet must contain before the engine may treat it as
evidence for `g_8`.

## Result

Artifact: `experiments/results/v2.54/g8_high_moment_measurement_specification.json`

Current route status:

```text
measurement_spec_defined_not_satisfied
```

Current claim-ready routes:

```text
none
```

The audit compares four designs:

| design | status | geometry isolation |
|---|---|---:|
| `forward_only_narrow` | rejected: forward degeneracy | no |
| `forward_only_wide_energy` | rejected: energy-reach artifact without EFT control | no |
| `high_moment_design_probe` | internal design probe; needs external mapping | no |
| `spin_0_2_4_partial_waves` | geometry works; still needs external measurement | yes |

The spin-0/2/4 design has the expected internal geometry: it adds pure `g_8`
rows and improves the `g_8` resolution fraction to 0.032 of the current
frontier range. This is useful experiment design. It is not a framework
exclusion.

## Measurement Contract

A promotable `g_8` route must provide all of the following:

| requirement | current status | blocker |
|---|---|---|
| external numerical observable or bound | missing | `missing_external_numeric_measurement` |
| source-backed map to the engine `g_8` axis | missing | `axis_mapping_not_source_backed` |
| angular/partial-wave/detector isolation from `g_4` and `g_6` | geometry only internal | `g8_not_isolated_from_lower_matter_moments` |
| public likelihood, covariance, or reproducible error budget | missing | `missing_public_likelihood_or_covariance` |
| EFT-valid energy/cutoff window | missing | `eft_validity_not_bounded` |
| closed calibration, angular acceptance, background, and EFT-truncation systematics | open | `systematics_not_closed` |
| registered-framework applicability domain | missing | `framework_domain_not_validated` |
| excluding discriminator math | missing | `discriminator_math_not_excluding` |

The packet template requires a public value or bound, uncertainty, covariance or
likelihood, an observable-basis normalization, a projection/Jacobian to `g_8`,
mixing control with `g_4/g_6`, and a bounded systematics budget.

## Guard Result

The current high-moment design probe is still blocked by the non-tower promotion
guard:

- `axis_mapping_not_source_backed`
- `discriminator_math_not_excluding`
- `external_measurement_evidence_not_ready`
- `internal_cut_not_external_measurement`
- `measurement_kind_not_external_numeric`
- `missing_external_numeric_measurement`
- `systematics_not_closed`

This is the desired behavior. The internal spin-map and Fisher geometry are
allowed to guide experiment design, but they cannot become an external
measurement claim.

## Interpretation

This loop improves the research program by turning a vague "measure `g_8`" idea
into a concrete evidence contract. It also closes two overclaim paths:

- wider forward-energy reach cannot count as `g_8` isolation without EFT-domain
  control;
- a toy spin-map cannot count as a source-backed observable-to-axis mapping.

The route remains unsolved. The next required artifact is an actual public
spin-4 partial-wave or asymptotic-detector-moment measurement packet satisfying
the contract and yielding excluding math against at least one registered
framework branch.
