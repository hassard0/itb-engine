v2.370 used ONE exact anomaly condition (inflow saturation) plus `g_R3_parity = 0` as input. The engine

## Result (yes -- the parity-odd sector is DETERMINED, not data-driven)

Both conditions are exact equalities in field theory:

```text
  (1) inflow:   g_R2_parity^2 + 2 g_R3_parity^2 = rho g_4 g_R2
  (2) t Hooft:  g_R3_parity = rho_match (g_4 + g_6) g_R2_parity = r * g_R2_parity   (r = 0.4645)

  => g_R2_parity = sqrt( rho g_4 g_R2 / (1 + 2 r^2) ) = 0.0654,   g_R3_parity = r * g_R2_parity = 0.0304
```

All 5/5 checks pass. The solution satisfies both equalities exactly, is globally feasible against the full
consistent+observed stack, and fixes the **full parity-odd sector from the parity-even sector alone, no data**
-- including a **nonzero parity-odd cubic** (0.0304), reversing the constructed center's `g_R3_parity = 0`
(the bound-form center, v2.352).

## The honest tension it exposes

This COMPLETE system fits the birefringence data **worse** than the incomplete saturation-only value:

```text
  closed system (both matched):  beta = 3.4 * 0.0654 = 0.222 deg   -> 1.31 sigma from 0.34 +/- 0.09
  saturation-only (cubic = 0):   beta = 0.266 deg (v2.370)         -> 0.82 sigma
  Chebyshev center:              beta = 0.204 deg                  -> 1.51 sigma
```

The nonzero cubic consumes anomaly budget and lowers the observable quadratic. So the data mildly prefers a
**suppressed cubic** (better fit, but then 't Hooft matching is not saturated) over the **fully-matched cubic**
(a complete theoretical determination, but a worse fit).
