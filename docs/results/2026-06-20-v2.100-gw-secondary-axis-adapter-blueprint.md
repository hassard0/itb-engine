## Gate Behavior

The adapter accepts only a synthetic fixture with:

- numeric source-parameter constraints
- source-to-engine Jacobian
- engine-axis likelihood export
- closed systematics
- bounded shared EFT domain

The real Liu-Yunes GW170608 paper-summary candidate supplies numeric
`alpha_bar_1` and `alpha_bar_2` constraints, but it is rejected because it still
lacks:

```text
source_to_engine_jacobian_missing
engine_axis_likelihood_export_missing
systematics_not_closed
shared_eft_domain_not_bounded
```

The dictionary-only source is also rejected because it is not an event
likelihood packet.
