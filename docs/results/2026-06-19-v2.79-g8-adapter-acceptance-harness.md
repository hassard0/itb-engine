## Question

v2.78 found useful partial-wave and detector-theory bridges, but no
engine-normalized `g_8` measurement packet. This iteration asks whether the
route can be made operational by defining the exact acceptance gate for a
future adapter packet.

## Acceptance Gate

A future `g_8` adapter packet must provide:

- external numerical value or bound with statistical and systematic uncertainty
- supported observable basis: spin-4 partial wave, asymptotic detector moment,
  or source-projected high moment
- source-backed Wilson-coefficient normalization to engine `g_8`
- bounded QG EFT energy/cutoff domain
- public covariance or likelihood containing `g_8`
- a pure `g_8` projection, or lower-moment `g_4`/`g_6` mixing controlled by
  public covariance
- closed systematics budget for angular acceptance, calibration, background,
  EFT truncation, and running/renormalization
- registered-framework applicability domain
- discriminator math that excludes a registered framework branch

## Interpretation

The route is now operationally testable: a future real source can be dropped into
the harness and either pass or fail without inventing new criteria. That is
progress, but it does not solve quantum gravity. The current source set still
lacks the hard object required for a claim: a public, source-backed, engine-
normalized `g_8` likelihood with exclusion math against registered frameworks.
