# v2.308 - CMB spectroscopy of the curvature tower? A clean hypothesis, honestly refuted

## Question

v2.307 found the cubic curvature operator R^3 (g_R3) shows up in the scalar tilt n_s. The clean
hypothesis going in: each higher curvature operator imprints on a higher derivative of the primordial
spectrum -- a "spectroscopy" `R^2 -> r`, `R^3 -> n_s`, `R^4 -> running alpha_s`. Adding the quartic R^4
(g_R4) and the running, does it hold?

## Result (refuted -- and the honest negative is the result)

No. The hypothesis is refuted, and what replaces it is sharper. Using f(R) = R + a R^2 + b R^3 + c R^4
inflation (validated by a strict b=c=0 self-check: n_s -> 1-2/N, and the running reproduces the
Starobinsky `-2/N^2`, alpha_s = -0.00064 vs -0.00066, within 5e-5):

```text
  sweep        n_s swing        running swing
  QUARTIC c    11.7 sigma       0.14 sigma      <- the quartic is an n_s handle, NOT a running handle
  CUBIC  b     14.0 sigma       0.10 sigma      <- as is the cubic
```

The quartic does **not** show up in the running -- it is *another* n_s handle, just like the cubic. Two
robust facts emerge instead:

**(1) The running is insensitive to the entire higher-curvature tower.** At engine-relevant magnitudes it
stays pinned at the Starobinsky `-2/N^2` whether the cubic or quartic is on (both move it < 0.15 sigma). So
a near-Starobinsky running is a robust engine prediction, and a future detection of a large `|alpha_s|`
would signal physics BEYOND a perturbative higher-curvature plateau -- not a specific operator.

**(2) The cubic and quartic are degenerate in n_s.** Both shift the tilt; neither shifts the running. So
the CMB shape observables `(r, n_s, alpha_s)` CANNOT spectroscopically separate g_R3 from g_R4.

## What this establishes (and how it sharpens v2.307)

n_s constrains a COMBINATION of the higher-curvature couplings, not g_R3 alone. The v2.307 reading
"n_s pins g_R3" survives only because the quartic is independently small: with the cubic pinned to
b ~ 2e-4, the moment-tower floor `g_R4 >= g_R3^2/g_R2` forces only `c >= 4e-8`, whose effect on n_s
(2.8e-4, < 0.07 sigma) and on the running (1.9e-4) is negligible. So WITHIN the engine the moment tower
breaks the degeneracy by fiat -- the forced quartic is too small to matter -- but the CMB itself cannot
see the difference. The degeneracy is real; the engine's moment structure is what makes n_s a clean g_R3
handle in practice.

## Honest scope

The headline is a refuted hypothesis, reported as such. The f(R) numerics are validated against the
analytic Starobinsky limit in all three observables (n_s to < 0.004, running to < 5e-5 of -2/N^2; the
wide-baseline slope cancels the smooth n_s bias, confirmed numerically), so the negative is a real
physical degeneracy, not a numerical artifact. The map from (g_R3, g_R4) to (b, c) is SCHEMATIC
(Planck-unit f(R) coefficients); the scan windows (|b| <= 1e-3, |c| <= 2.5e-5) keep the higher operators
as controlled perturbations of the plateau, not poles. The robust, prefactor-independent content:
(i) near-Starobinsky running is insensitive to the curvature tower; (ii) n_s constrains a g_R3/g_R4
combination, degeneracy-broken within the engine only because the moment-tower floor makes the quartic
negligible. The Starobinsky amplitude (a ~ 1e9) is not addressed (shape only). Single-field slow-roll;
b<0/c<0 poles unexplored. Toy basis, O(1) prefactors.
