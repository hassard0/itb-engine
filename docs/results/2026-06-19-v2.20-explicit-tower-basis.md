## Question

v2.16-v2.19 showed that every coefficient-only replacement for the hard distance prior
remains redundant in the 8D Wilson basis. v2.20 asks the next sharper question:

> If the engine adds an independent tower/moduli coordinate, can a tower-sector cutoff
> create a genuinely new gate?

The extension adds:

```text
phi_tower
```

outside `Theory.coefficients`, so old coefficient constraints cannot accidentally act on
it. The diagnostic tower model is:

```text
m_tower(phi) = m0 * exp(-lambda * phi)
Lambda_s = 1 / sqrt(1 + rho * (Lambda_s / m_tower)^p)
allowed iff Lambda_EFT <= Lambda_s
```

`Lambda_s` is solved self-consistently by bisection. This is still a diagnostic
basis-extension test, not a physical SDC implementation.

## Result

At `Lambda_EFT = 0.65`, the explicit tower coordinate creates a large 9D gate:

| quantity | value |
|---|---:|
| reference-feasible extended points | `110106` |
| candidate-feasible extended points | `48936` |
| explicit tower gate count | `61170` |
| sampled growth when tower gate is removed | `125.0%` |
| gated points that pass old distance and species | `12440` |
| critical `phi_tower` | `0.7433` |
| critical tower mass | `0.4755` |
| critical species cutoff | `0.6500` |
| allowed phi-grid fraction per 8D survivor | `0.444` |

The `Lambda_EFT` sensitivity is strong:

| `Lambda_EFT` | critical `phi_tower` | gate count | sampled growth |
|---:|---:|---:|---:|
| `0.50` | `1.7918` | `0` | `0.0%` |
| `0.60` | `1.0862` | `36702` | `50.0%` |
| `0.65` | `0.7433` | `61170` | `125.0%` |
| `0.70` | `0.3967` | `85638` | `350.0%` |

The solver and isolation checks pass:

- bisection residual is zero at recorded precision,
- `0 < Lambda_s <= 1` for edge cases,
- `m_tower` decreases with `phi_tower`,
- species count increases with `phi_tower`,
- species cutoff decreases with `phi_tower`,
- old corrected-stack verdicts are invariant under changing `phi_tower`,
- every 8D survivor still has at least one allowed `phi_tower` value.

## Interpretation

This is the first positive result after the v2.16-v2.19 negative sequence, but it must be
phrased carefully.

The positive claim:

> An independent tower coordinate can add a nonredundant diagnostic gate that coefficient
> norms and latent coefficient-derived tower variables could not provide.

The caveat:

> This is not yet framework discrimination. Existing framework encoders supply Wilson
> coefficients but no justified `phi_tower`; therefore no framework should be excluded
> until `phi_tower` is assigned by a model or measured by an observable.

The projection audit matters. The 9D fiber over each 8D survivor is restricted, but the
8D projection is unchanged because `phi_tower = 0` remains allowed. That means the new
coordinate points to the next missing observable: a direct bound or measurement of tower
mass/species cutoff/moduli distance.

## Bottom line

The engine still has not solved quantum gravity. v2.20 identifies the first genuinely
new axis after the distance-prior failure: an explicit tower/moduli coordinate can add
independent discrimination, but only in 9D and only as a fiber restriction. Turning it
into a framework-level discriminator requires assigning or measuring `phi_tower`.
