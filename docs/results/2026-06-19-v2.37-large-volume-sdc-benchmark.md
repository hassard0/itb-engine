## Question

v2.36 ended with two possible next moves: asymptotic lightest-tower extraction or a
compactification source above the tower threshold. v2.37 asks:

> Does a primary-source large-volume SDC fit cross the tower threshold?

Yes, under a one-Planck benchmark displacement. But the benchmark displacement is not
a native framework prediction, so this is not a framework-level exclusion.

## Source

Primary source:

- Ralph Blumenhagen, Daniel Klaewer, Lorenz Schlechter, and Florian Wolf,
  "The Refined Swampland Distance Conjecture in Calabi-Yau Moduli Spaces",
  `arXiv:1803.04989`

The source fits asymptotic large-volume behavior for the quintic using:

```text
Theta(t) ~= lambda^-1 log(t) + alpha0 + alpha1/t^3
```

Table 3 reports ten `lambda^-1` values between `0.8657` and `0.9865`. This audit
uses the conservative interpretation `phi_tower = lambda_sdc * Delta_moduli`, with:

```json
{
  "lambda_sdc_min": 1.013684744044602,
  "lambda_sdc_mean": 1.0722604261754038,
  "lambda_sdc_angular_sigma": 0.045623759875811055
}
```

It intentionally does not use the stronger rough relation `M_KK ~ exp(-2 lambda Theta)`.

## Result

For `Delta_moduli = 1`:

```json
{
  "framework_tower_verdict": "tower_excluded_by_predictive_spectrum",
  "two_sigma_phi_interval": [0.9810129064237817, 1.1635079459270259],
  "critical_phi_tower": 0.7433019116911739,
  "conservative_delta_moduli_required_for_exclusion": 0.7576882086096424,
  "claimable_now": false
}
```

The evidence schema passes, and the tower math excludes under the benchmark. The
claim is still blocked by:

- `Delta_moduli = 1` is a benchmark, not a framework-owned prediction
- angular variation is not a statistical uncertainty
- the row is not native `string_tree_eft.tower_evidence()`
- generic `string_tree_eft` does not select a large-volume endpoint

## Bottom line

The frontier moved. The blocker is no longer only missing primary-source tower data:
there is now a primary-source large-volume benchmark that crosses the tower threshold.
The remaining blocker is ownership of the displacement and endpoint. A future claim
needs a framework or compactification model that natively commits to the large-volume
trajectory and `Delta_moduli` range.
