## Finding

The repo can define, validate, and consume a `g_8` measurement packet. It cannot
create the external measurement, public likelihood, or component systematics
required for that packet.

External requirements still missing:

- external numerical spin-4/detector observable
- public `g_8` likelihood or covariance
- component-level systematics budget
- bounded low-energy QG EFT domain

The framework-exclusion calculation can be done in the repo only after that
external packet exists.

## Interpretation

This is an external-state blocker, not an implementation gap in the adapter
harness. The next honest step is either to obtain an external published
spin-4/detector `g_8` packet or retire this route for the current in-repo run and
reprioritize.
