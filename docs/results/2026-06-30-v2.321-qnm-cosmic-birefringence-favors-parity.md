# v2.321 - The measured cosmic birefringence favors parity-violating gravity

## Question

The new-theory program's parity finding (the preferred framework is mildly parity-violating, driven by
anomaly matching, v2.318) made a falsifiable chiral-GW prediction (v2.319). Is that parity direction
supported or excluded by current data?

## Result (supported -- a real-data convergence)

Supported, and strikingly so. The engine's `cosmic_birefringence_data` constraint encodes the measured
isotropic cosmic-birefringence angle `beta = 0.34 +/- 0.09 deg` (Minami-Komatsu 2020 / Eskilt-Komatsu 2022,
Planck PR4 + WMAP) -- nonzero at ~3.6 sigma -- via `beta_pred = 3.4 deg * g_R2_parity`. A nonzero `beta`
DEMANDS a parity-odd coupling:

```text
  framework           g_R2_parity   beta_pred (deg)   data-favored
  pure_gr             0.000          0.000             NO  (excluded ~3.6 sigma)
  string_tree_eft     0.000          0.000             NO
  asymptotic_safety   0.000          0.000             NO
  cdt                 0.000          0.000             NO
  lqg_induced         0.080          0.272             yes
```

The four parity-EVEN frameworks predict `beta = 0` and are DISFAVORED by the data. The data requires
`g_R2_parity >= 0.048` (its 2-sigma lower edge) and centers on `g_R2_parity = 0.10` (1-sigma band
[0.074, 0.126]); lqg (0.08) sits inside that band. The anomaly-preferred parity (0.038, v2.318) is just
below the 2-sigma data edge -- so consistency and data AGREE on the sign and existence of parity violation
(both want `g_R2_parity > 0`, right-handed), with the data wanting a somewhat larger magnitude. They are
mutually satisfiable: a constructed framework with parity in the joint window **[0.048, 0.078]** passes
BOTH all the consistency constraints AND the cosmic-birefringence data. All 5/5 checks pass.

## What this establishes

Three independent lines now point the same way:

```text
  consistency condition   anomaly matching prefers g_R2_parity ~ 0.038 > 0     (v2.318)
  real measurement        cosmic birefringence requires g_R2_parity >~ 0.048   (this cycle)
  future observable       chiral primordial GW, sourced by the SAME g_R2_parity (v2.319)
```

All select mild, right-handed parity violation and disfavor the parity-even frameworks. The new-theory
program's parity finding is thus not merely internally motivated but aligned with the one tantalizing
parity-odd signal in current cosmological data -- and it predicts a correlated tensor-sector signature
(chiral GW) as the next test.

## Honest scope

The discriminator and the sign are robust; the magnitude is encoding-dependent. The cosmic-birefringence
DETECTION is itself ~3.6 sigma (tantalizing, not confirmed), and the engine's `beta_pred = 3.4 deg *
g_R2_parity` is an order-of-magnitude normalization (per the engine's own docstring), so the data-required
parity (~0.048 threshold, ~0.10 central) carries that O(1) uncertainty; what is robust is that a nonzero
measured `beta` requires `g_R2_parity != 0` with `sign(beta) = sign(g_R2_parity)`, excluding parity-even
gravity. The frameworks' exclusion is exact given the data constraint. The "convergence" is a same-sign,
same-order-of-magnitude agreement (anomaly optimum 0.038 vs data band ~0.07-0.13 at 1 sigma), not a precise
coincidence -- the data wants somewhat more parity than anomaly matching alone, and the joint window is
where both are satisfied. The chiral-GW link shares the same schematic `g_R2_parity -> observable` map.
Real published data read through the engine's toy encoding; the qualitative alignment is the result, not a
fit. Toy basis, O(1) prefactors.
