# v1.63 — `itb predict <framework>`: the whole program as one command

**Date:** 2026-06-08
**Compute:** Vulcan.

---

## What this adds

A unified predictions layer that turns the entire program into a usable tool:
`src/itb/predict.py` + the `itb predict <framework>` CLI subcommand emit, for any
of the 11 catalogued frameworks, its **complete falsifiable fingerprint** in one
report. 7 tests; full suite **405 green**.

## The fingerprint, per framework

| field | meaning | source cycle |
|---|---|---|
| scope verdict | in/out of the engine's validity (local + Lorentz-invariant) | v1.58/59 |
| forward-positivity ratio g_R2/g_R3 | the load-bearing cubic-suppression number | v1.24 |
| sub-mm Yukawa range (µm) | R²-Stelle deviation at the dark-energy cutoff | v1.40 |
| GW birefringence \|g_R2_parity\| | LIGO O5 target | v1.41/46 |
| chiral Hellings–Downs Π_V (%) | SKA-PTA circular polarization | v1.53 |
| cosmic-birefringence sibling | EM (CMB EB) expectation | v1.46/48 |

So a single command answers "if nature is framework X, what would every
experiment measure, and is the engine even entitled to judge it?" — consolidating
the gravitational-observable program (v1.40–53), the scope layer (v1.58–59), and
the realism-corrected coefficients into one user-facing output. Combined with the
inference layer (v1.52, the inverse direction: measurement → posterior), the
engine now runs both ways: theory → predictions, and data → surviving theories.

## Honest limitations

The observable values inherit every model-dependence already flagged: the Yukawa
and birefringence amplitudes assume the dark-energy-scale cutoff; Π_V carries the
O(1) axion-evolution factor; the cosmic-birefringence sibling assumes the common
axion. `predict` reports the *fingerprint*, not feasibility against the full
research stack (that lives in `experiments/stack.py`); out-of-scope frameworks
get observables shown but the scope flag makes clear the engine declines to
adjudicate them.
