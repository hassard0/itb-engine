For each in-scope reference-feasible framework, the audit inspected the encoded
`Theory.coefficients`, `Theory.metadata`, and framework attributes for:

- `phi_tower`
- `tower_mass_gap`
- `radius_ratio` or `R/R0`
- `delta_moduli`
- `lambda_sdc`

No current in-scope reference-feasible encoder contains any of those tower inputs.
The current framework catalogue is therefore Wilson-coefficient data only for this
purpose.

## Guardrail

This is not a literature exhaustion proof. It only says the repository cannot derive
the required `TowerEvidence` row from its current framework encoders.

The SDC sources already audited in v2.26 still motivate the tower route but do not
provide an engine-ready evidence row by themselves:

- Hirosi Ooguri and Cumrun Vafa, "On the Geometry of the String Landscape and the Swampland" (`hep-th/0605264`)
- Pierre Corvilain, Thomas W. Grimm, and Irene Valenzuela, "The Swampland Distance Conjecture for Kahler moduli" (`1812.07548`)

## Required next data

The highest-value targets now need one of the following:

| framework | required next data |
|---|---|
| `string_tree_eft` | Compactification-specific `R/R0` or `Delta_moduli` with uncertainty, normalization, and primary source |
| `asymptotic_safety` | Sourced RG-to-tower map or scale spectrum with `phi_tower` normalization and uncertainty |
| `cdt` | Sourced continuum-limit geometric spectrum mapped to tower mass, radius ratio, or moduli distance with uncertainty |
| `discovered_*` | External evidence or reproducible computed-spectrum artifact; generated Wilson coefficients alone are not an allowed source |
| `pure_gr` | A UV-completion or null-baseline decision with sourced tower evidence |

## Bottom line

The next loop cannot honestly be another local reinterpretation of the same Wilson
coefficients. To move toward a claim, the project has to add new sourced data to at
least one framework or explicitly change the catalogue to mark a null/baseline tower
case.
