## What Changed

v2.209 reads what each public source actually provides (fetched 2026-06-29) and turns
the open "map missing" status into a precise, source-cited rank determination. It does
not invent sensitivity numbers; it records an observability/rank statement.

Three primary-source facts:

```text
1. Bresciani operator basis (arXiv:2504.12855) is a pure amplitude/positivity paper.
   It defines exactly three real quartic operators via c_plus = c1 + c2 (real,
   parity-even) and c_minus = c1 - c2 + i*c3 (complex), operators (Q2)^2, (Q2tilde)^2,
   Q2.Q2tilde. It has ZERO black-hole / QNM / ringdown content and NO map to QNM
   deformations. => operator-basis rank 3 is source-backed; the qNM->operator edge is
   absent here.

2. The only public ringdown ANALYSIS with real GW150914/GW200129 likelihoods over EFT
   operators (qEFT route, arXiv:2411.17893) reduces each theory to a single combined
   length scale ell ("we can always set lambda = +/- 1"), i.e. rank 1 per parity-even
   theory family, and EXPLICITLY defers the parity-violating sector ("we leave such
   extension to future study"). => the engine's third axis g_R4_c3 = Im(c_minus) (the
   parity-odd Q2.Q2tilde operator) is unconstrained by any public ringdown analysis.

3. The QNM-shift computation source (Cano-Fransen-Hertog-Maenaut arXiv:2307.07431, and
   arXiv:2110.11378) computes parity-even and parity-odd shifts; the parity-odd shift
   enters only via rotation-induced parity mixing and has NO attached public likelihood.
   Computable-in-principle, not source-backed-observable.
```

Conclusion: a source-backed rank-3 qNM-to-Bresciani map does NOT exist. The maximum
source-backed observable rank over the engine axes is 2 (the two parity-even quartic
directions; realized as rank 1 per theory in the public analysis), and the parity-odd
third axis g_R4_c3 is dark. This preserves the negative result the roadmap requires.


## Roadmap Impact

This narrows roadmap items 1-2. A full-rank claim now provably requires more than the
public qEFT/pyRing route can give: it needs a polarization- or rotation-resolved source
that constrains the parity-odd Q2.Q2tilde operator. Until such a source exists, the
defensible R4 ringdown product is at most a parity-even, rank-1-per-theory nonclaiming
null test (the v2.208 pyRing runtime rerun), explicitly flagged as not constraining
g_R4_c3.
