## Gate Behavior

The adapter now requires a source-native alpha packet with:

- `alpha_bar_1` and `alpha_bar_2` constraints
- source-native posterior samples, covariance, or reproduced likelihood
- source-parameter covariance
- waveform model reference
- normalization convention
- engine-axis strategy and framework-projection strategy
- closed systematics
- bounded source-native cubic GW EFT domain

The synthetic complete packet passes the source-native adapter shape, but remains
non-claiming because it is synthetic, has no engine projection, and has no `g_8`
joint component.

The real Liu-Yunes paper-summary candidate is rejected because it has intervals
but lacks a public source-native likelihood/covariance export and closed adapter
systematics:

```text
missing_required_fields
source_native_likelihood_export_missing
source_parameter_covariance_missing
systematics_not_closed
shared_eft_domain_not_bounded
```

The public O2 BBH posterior release is also rejected for this adapter because it
contains GR binary-parameter posteriors, not `alpha_bar_1` / `alpha_bar_2`
modified-gravity evidence.
