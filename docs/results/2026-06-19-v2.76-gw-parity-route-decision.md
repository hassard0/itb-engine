# v2.76 - GW parity route decision: direct Ng promotion retired

## Question

v2.75 showed that no current engine parity axis can accept the Ng/Jenks
`beta_1_0` candidate packet. This iteration turns that into an explicit route
decision so the source-native likelihood cannot be accidentally reused as a
framework discriminator.

## Interpretation

The GW parity branch produced real progress: verified public data, a reproduced
Ng restricted `kappa` likelihood, and a guarded source-native PPV candidate
packet. It did not produce an engine-normalized quantum-gravity discriminator.

The honest next move is not another parser. It is either a source-backed
operator-normalization map into the engine Wilson basis or a pivot to a
different discriminator frontier with a cleaner measurement contract.
