## Interpretation

The Ng route now has both public posterior products under guard: the Gaussian
hyperposterior NPZ and the full event-level Feather table. This closes the
large-file ingestion blocker and provides source-native event `kappa` samples.

It still does not produce the restricted global `kappa` likelihood used for a
single-population parity constraint, a sign-harmonized PPV `beta_1_0`
likelihood, or any `g_R2_parity` / `g_R3_parity` engine projection.
