# v2.55 - g8 existing measurement packet search: public data exists, but not for engine g8

## Question

v2.54 defined the packet needed to promote the `matter_high_moment_g_8` route.
This loop asks whether existing public measurements already satisfy that packet,
especially collider energy-correlator measurements and detector/partial-wave
theory bridges.

## What Exists

There is real external data near the route:

- CMS has measured two- and three-particle energy correlators inside jets and
  provides tabulated results through HepData.
- CMS open-data work demonstrates multipoint energy correlators in real LHC
  data.
- CMS heavy-ion EEC measurements provide pp/PbPb ratios with statistical and
  systematic uncertainties, plus HepData links.
- Detector operators and hadron-collider EEC partial-wave decompositions provide
  theory language that could help build a future adapter.

## Why It Still Fails

Every candidate fails the `g_8` contract:

| contract failure | count |
|---|---:|
| `source_backed_g8_axis_mapping` | 5 |
| `framework_applicability_domain` | 5 |
| `eft_valid_energy_window` | 5 |
| `excluding_discriminator_math` | 5 |
| `public_likelihood_or_covariance` | 5 |
| `angular_or_partial_wave_isolation` | 5 |
| `external_numeric_observable` | 5 |
| `closed_systematics_budget` | 3 |

The external CMS measurements are valid QCD measurements, not quantum-gravity
`g_8` measurements. The theory bridges are useful for designing an adapter, but
they are not numerical data. None supplies an engine-normalized likelihood,
source-backed projection/Jacobian to `g_8`, registered-framework EFT domain, or
framework exclusion.

## Interpretation

The route did not fail because no nearby experimental technology exists. It
failed because the existing data are not mapped to the engine's
quantum-gravity `g_8` coefficient. That is a narrower and more useful blocker.

The next useful artifact is either:

- a source-backed adapter deriving an engine-normalized `g_8` likelihood from
  spin-4/energy-correlator data; or
- a new measurement design whose observable is built directly around the
  `g_8` contract.

No solution claim is available from this route.
