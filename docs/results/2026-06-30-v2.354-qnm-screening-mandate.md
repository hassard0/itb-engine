# v2.354 - The theory MANDATES screening: an unscreened dark-energy-scale R^2 fifth force is excluded (a third channel)

## Question

A genuinely fresh channel. Every consistent+observed cycle so far has used `submm_screened=True`, treating
it as a neutral convenience. Is it? The sub-mm gravity (Eot-Wash) data constraint, *unscreened*, caps
`g_R2 <= 0.063` -- but the constructed theory has `g_R2 = 0.193`. What does that mean?

## Result (the flag is load-bearing -- the theory requires a screened scalaron)

```text
  unscreened Eot-Wash cap:  g_R2 <= 0.0626      constructed g_R2 = 0.193   (3.08x over)
  constructed unscreened violations:  ['submm_gravity_yukawa_bound']   (ONLY this fails)
  constructed screened violations:    none (fully feasible)
  analytic g_4 floor for unscreened feasibility:  0.59
  unscreened feasible point in 30000 samples:     NONE  ->  region empty
```

The constructed value is not an accident: the consistency + observed constraints **force** `g_R2` well above
the unscreened cap. Analytically, anomaly inflow (`g_R2_parity^2 <= rho g_4 g_R2`) plus the cosmic-
birefringence floor (`g_R2_parity >= 0.0471`) give `g_R2 >= 0.037/g_4`, so meeting the cap would require
`g_4 >= 0.59` -- a thin sliver -- and the remaining `g_R2`-raising constraints (graviton forward positivity,
cross-sector EFThedron, anomaly cancellation) close even that. A 30000-point search under the unscreened
stack finds no feasible theory. All 5/5 checks pass.

## What this establishes

The constructed theory makes a definite **third-channel prediction** (after parity/birefringence and
ringdown): its R^2 fifth force **must be screened** (chameleon / Vainshtein / dark-sector). The
`submm_screened=True` flag used throughout the program is therefore **load-bearing**, not a convenience. This
is falsifiable in the same Eot-Wash channel that motivates it -- a confirmed unscreened dark-energy-scale
fifth force would exclude the constructed theory outright. It also reframes the parity headline's companion:
the *same* birefringence floor + anomaly inflow that v2.350 used to lower-bound `g_4 g_R2` is what pushes
`g_R2` past the Eot-Wash cap and forces screening.

## Honest scope

The emptiness of the unscreened region is an **empirical** search result (a large random sample, not an
analytic proof), but it is corroborated by the analytic lower bound on `g_R2` (anomaly inflow + birefringence
-> `g_R2 >= 0.037/g_4`, needing `g_4 >= 0.59` even before the other three `g_R2`-raising constraints) and by
the constructed point failing *only* the sub-mm bound unscreened. The `g_R2_max ~ 0.063` is a DATA reading
with order-of-magnitude uncertainty (the Eot-Wash curve points are read off the published figure; the
`alpha = 1/3` scalaron strength and 2.4 meV dark-energy cutoff are model inputs) -- so the exact 3.08x factor
is soft, but the qualitative gap (`g_R2 ~ 0.19` forced vs cap `~ 0.06`) is an order of magnitude clear. The
result inherits the anomaly prefactor `rho` (v2.344) and the cosmic-birefringence detection being real
(v2.329): if birefringence is a systematic, `g_R2_parity` can vanish, the anomaly floor on `g_R2` relaxes,
and a small-`g_R2` unscreened branch might reopen -- so the screening mandate is contingent on the same data
as the parity headline. Robust content: the consistency+observed constraints force `g_R2` well above the
unscreened Eot-Wash cap, so the theory requires a screened scalaron. Toy basis, O(1) prefactors.
