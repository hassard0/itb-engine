# v2.465 - the scale-clean UV-embedding fingerprint: every moment-tower double-ratio is scale-independent

v2.464 showed the curvature double-ratio D = (g_R2·g_R4)/g_R3² is scale-independent. That's a **general** feature of
moment towers. In a string α′ expansion any moment coupling scales as g_k ~ x^k·b_k (x = α′·M_Pl², b_k the O(1)
coefficient), so for any consecutive triple

```text
  D_k = (g_{k-1} g_{k+1}) / g_k^2 = b_{k-1} b_{k+1} / b_k^2 ,   x-power (k-1)+(k+1)-2k = 0  ->  alpha' CANCELS
```

So **every** moment-tower consecutive-rung double-ratio is scale-independent — a whole *family* of scale-clean
UV-embedding tests, one per triple in the matter positivity tower and the curvature tower. 5/5 checks pass.

## The candidate's scale-clean fingerprint

```text
  matter     (g_4 g_8)/g_6^2    = 1.32
  matter     (g_6 g_10)/g_8^2   = 1.00   (g_10 at tower floor 0.40)
  curvature  (g_R2 g_R4)/g_R3^2 = 1.00   (g_R4 at tower floor 0.042)
```

Each is a pure number, all ≥ 1 (moment-tower ratios g_k² ≤ g_{k−1}·g_{k+1}). This is the candidate's **scale-clean
UV fingerprint** — the full set of dimensionless numbers a heterotic (or any string) embedding must match, *without
the string scale*. The matter double-ratios are ratios of the string's **Virasoro–Shapiro ζ-value coefficients**
(computable in principle from the tree-level 4-point amplitude); the curvature one involves the basis-dependent
R³/R⁴ coefficients (the v2.464 caveat).

Together they upgrade the "blocked on the string scale" UV embedding (v2.434) into a concrete, scale-clean
**fingerprint-matching problem**: a string embedding is confirmed if its coefficient ratios reproduce the
fingerprint, refuted if they can't — all scale-independently. This is the systematic generalization of the single
scale-clean test (v2.464) into the candidate's complete scale-independent UV signature.

## Honest scope

The general scale-independence is **exact** (the x-powers cancel for every consecutive-rung double-ratio) — the
genuine new content. But this cycle still does **not** compute the string fingerprint: the matter b_k are the
Virasoro–Shapiro ζ-value coefficients (computable in principle, but I don't derive them — the forward-limit
bookkeeping is exactly the amplitude subtlety I avoid to prevent error), and the curvature c_k are
field-redefinition-basis-dependent. So the test is *opened as a fingerprint, not executed*. The candidate's
*values* carry constructed-point caveats: (g_4 g_8)/g_6² = 1.32 partly reflects the g_6 = g_8 Chebyshev artifact,
and the two floor values (1.00) are moment-tower-floor saturation by the Chebyshev point — so the robust candidate
statement is only that each entry is ≥ 1 (the rigorous moment-tower inequality). A **method** generalization, not
a completed string comparison.
